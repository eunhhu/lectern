개인정보처리방침

공고일·시행일: {{EFFECTIVE_DATE}}

Lectern(이하 "서비스", lectern.qucord.com과 Lectern 데스크톱·모바일 앱)은 녹음과 문서를 받아 전사(받아쓰기)와 정리된 문서를 만들어 주는 서비스입니다. 이 방침은 서비스 운영자(이하 "운영자")가 이용자의 개인정보를 어떻게 수집하고, 쓰고, 보관하고, 다른 곳에 맡기는지 설명합니다. 운영자는 「개인정보 보호법」 등 관련 법령을 지킵니다.

요약
  • 계정 정보(이메일, 이름)와 이용자가 올린 녹음·PDF, 그리고 그것으로 만든 전사와 문서를 처리합니다.
  • AI 처리를 위해 녹음과 텍스트를 Google Gemini API(유료 서비스)로 보냅니다. Google은 유료 서비스의 입력과 결과를 자사 제품 개선에 쓰지 않습니다.
  • 이용자의 녹음과 문서를 광고, 판매, AI 모델 학습에 쓰지 않습니다.
  • Google 캘린더를 연결하면 Lectern이 만든 전용 캘린더에만 일정을 씁니다. 다른 캘린더는 읽지도 쓰지도 않습니다.
  • 삭제한 데이터는 서버에서 바로 지워지고, 백업 사본은 최대 7일 뒤 사라집니다.

1. 수집하는 개인정보와 수집 방법

1.2 서비스가 만들어 내는 정보

제공하는 기능에 따라 다음 정보가 만들어집니다.

  • 녹음을 받아쓴 전사(시간 정보와 화자 구분 포함), 요약·노트 등 정리된 문서, 녹음에서 찾아낸 일정·할 일·질문
  • 처리 상태와 처리에 쓰인 AI 모델 이름, 처리 기록(작업 기록)
  • 공유 링크 정보(공개 여부, 링크 토큰)

1.3 서비스 이용 중 자동으로 생성되는 정보

  • 인증 정보: 로그인 세션 토큰(쿠키), 앱과 단축어 연동용 API 토큰, 이메일 인증번호
  • 보안 기록(감사 로그): 로그인, 비밀번호 변경, 토큰 재발급, 관리자 작업 같은 계정 활동의 종류, 시각, 계정 이메일
  • 서버 운영 기록: 요청 방법, 주소 경로, 응답 코드, 처리 시간. 주소에 들어 있는 토큰 같은 자격 증명은 가린 뒤 기록합니다.
  • 접속 IP 주소: 로그인·인증번호 요청 횟수 제한(무차별 대입 방지)을 위해 서버 메모리에서만 잠시 쓰고 저장하지 않습니다. 네트워크 보안 업체(Cloudflare)는 모든 접속을 중계하는 과정에서 IP 주소를 처리합니다(4장).
  • 사용한 앱 종류: 녹음을 올린 클라이언트(웹, macOS, Android 등)

1.5 기기(브라우저·앱)에 저장되는 정보

  • 로그인 유지를 위한 세션 쿠키(lectern_session, HttpOnly·Secure). 서비스에 꼭 필요한 쿠키이며 광고·분석용 쿠키나 추적 도구는 쓰지 않습니다. 브라우저 설정으로 쿠키를 거부할 수 있지만, 그러면 로그인이 필요한 기능을 쓸 수 없습니다.
  • 화면 테마 같은 설정, 업로드를 기다리는 녹음(네트워크가 끊겼을 때 다시 보내기 위해 이용자 기기에만 저장)
  • 데스크톱·모바일 앱의 API 토큰(기기의 보안 저장소 또는 앱 설정)

2. 개인정보를 쓰는 목적

  1. 서비스 제공: 녹음 저장과 재생, AI 전사와 문서 생성, 일정·할 일·질문 추출, 검색, 공유 링크, (연결한 경우) Google 캘린더 일정 등록
  2. 계정 관리: 가입, 본인 확인, 로그인, 비밀번호 재설정 메일 발송, 저장 용량 관리
  3. 보안과 부정 이용 방지: 요청 횟수 제한, 보안 기록, 장애 원인 분석
  4. 문의 응대와 공지: 문의 답변, 서비스 변경이나 장애에 관한 안내

운영자는 이용자의 녹음, 전사, 문서를 광고에 쓰거나 판매하지 않고, AI 모델을 학습시키는 데 쓰지 않습니다. 서비스 품질을 평가할 때는 녹음 당사자에게 따로 동의를 받은 녹음만 씁니다.

운영자(관리자)는 장애 대응, 이용자 문의 처리, 법령 준수, 약관 위반 확인처럼 서비스 운영에 꼭 필요한 경우에만 이용자의 콘텐츠를 열람합니다.

4. 처리 위탁과 국외 이전

운영자는 서비스를 제공하기 위해 아래 업체에 개인정보 처리를 맡깁니다. 이 업체들은 모두 해외에 있으므로 개인정보가 국외로 이전됩니다. 이전은 이용자가 서비스를 쓸 때 암호화된 네트워크(HTTPS)로 그때그때 이루어집니다.

국외 이전을 거부하려면: 위 업체를 거치지 않고는 서비스를 제공할 수 없으므로, 거부하려면 서비스 이용을 멈추고 계정 삭제를 요청하면 됩니다. Google 연동은 연결하지 않거나 언제든 해제해 거부할 수 있습니다.

이용자가 업로드할 때 자기 Gemini API 키를 직접 넣는 경우, 그 녹음은 이용자의 키로 처리되며 그 키에 적용되는 Google 약관을 따릅니다(무료 계층 키라면 Google이 입력을 제품 개선에 쓸 수 있습니다). 운영자는 그 키를 해당 처리 작업 동안만 암호화해 보관하고, 작업이 끝나면 지웁니다.

운영자는 법령에 따른 요청이 있는 경우를 빼고 이용자의 개인정보를 제3자에게 제공하지 않습니다. 이용자가 공개로 설정한 공유 링크는 링크를 아는 누구나 볼 수 있습니다.

5. Google 사용자 데이터

Lectern이 Google API로 받은 정보를 쓰거나 다른 앱으로 보내는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

  • Google 사용자 데이터는 1.4에 적은 로그인과 캘린더 일정 동기화 기능에만 씁니다.
  • Google 사용자 데이터를 광고에 쓰거나, 팔거나, 데이터 중개업자 등 제3자에게 넘기지 않습니다.
  • Google 사용자 데이터를 AI·머신러닝 모델을 만들거나 학습시키거나 개선하는 데 쓰지 않습니다.
  • 사람이 Google 사용자 데이터를 읽는 것은 이용자가 동의한 경우, 보안 목적(남용 조사 등), 법령 준수에 필요한 경우로만 제한합니다.
  • 연결 해제: 서비스 설정에서 연결을 해제하거나, Google 계정의 서드파티 연결 관리에서 Lectern의 접근 권한을 삭제할 수 있습니다. 해제하면 운영자가 보관한 Google 토큰을 지웁니다.

Google API disclosure: Lectern's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only for sign-in and for syncing events to the calendar Lectern creates; it is not sold, not used for advertising, and not used to train AI or machine-learning models.
