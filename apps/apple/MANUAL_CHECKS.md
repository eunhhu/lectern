# 실제 기기에서만 확인되는 것

게이트(`scripts/gate.sh`)는 시뮬레이터 빌드와 SwiftPM 단위 테스트만 본다(CONTRACTS D-P6-9).
아래 항목은 사람이 실제 기기에서 확인한다. 확인하기 전에는 "통과"라고 적지 않는다.

| # | 작업 패키지 | 확인할 것 | 방법 | 결과(날짜, 기기, OS) |
|---|---|---|---|---|
| 1 | P6-A3 | 업로드 중 앱을 강제 종료해도 이어서 올라간다(받은 파트는 다시 보내지 않는다) | 30분 이상 녹음을 올리다 앱 전환기에서 앱을 끄고 다시 연다. 서버의 `GET /api/v2/uploads/{id}` `received_parts`가 이어서 늘고 녹음이 하나만 생긴다 | |
| 2 | P6-A3 | 비행기 모드에서 녹음을 끝내고, 네트워크가 돌아오면 올라간다 | 비행기 모드로 녹음을 끝낸 뒤 대기열이 "네트워크 기다리는 중"인지 보고, 비행기 모드를 끈다 | |
| 3 | P6-A3 | 1GB 파일 업로드 중 메모리 사용이 일정하다 | Instruments(Allocations)로 1GB 파일을 올리는 동안 메모리가 파트 크기 수준에서 평평한지 본다 | |
| 4 | P6-A4 | 전화가 오면 일시정지되고, 끝나면 재개를 묻는다 | 녹음 중 다른 기기로 전화를 걸어 받고 끊는다. 통화 중에는 파일 길이가 늘지 않고, 끊은 뒤 재개(또는 재개 제안)되며 이어서 녹음된다 | |
| 5 | P6-A4 | AirPods를 빼면 일시정지된다 | AirPods로 녹음하다 케이스에 넣는다. 일시정지(경로 끊김)가 되고, 다시 끼우거나 재개하면 이어서 녹음된다 | |
| 6 | P6-A4 | 화면을 끈 채 3시간 녹음 뒤 파일 길이가 맞다 | 잠금 화면 상태로 3시간 녹음하고 끝낸다. 파일 길이가 벽시계 시간에서 일시정지를 뺀 값과 1초 안으로 같고, 마커가 그 시점의 소리와 맞는다 | |
| 7 | P6-A4 | 무음 20초에 경고가 뜬다 | 마이크를 막고 20초 기다린다. 경고가 뜨고, 소리를 내면 사라진다 | |
| 8 | P6-A4 | 녹음 중 다른 이어폰·USB 마이크를 연결해도 녹음이 이어진다 | 녹음 중 유선 이어폰(또는 Mac의 USB 마이크)을 연결한다. 엔진이 형식 변경 뒤 스스로 다시 시작해 파일에 빈 구간 없이 이어진다 | |
| 9 | P6-A4 | 녹음 중 앱이 강제 종료되면 그 파일은 읽을 수 없다(현재 형식의 한계) | 녹음 중 앱 전환기에서 앱을 끈다. m4a는 끝낼 때 색인을 쓰므로 남은 파일은 재생되지 않는 것이 예상이다. 확인 뒤 형식(CAF 등) 변경 여부를 정한다(STATUS) | |
| 10 | P6-A5 | 가장 큰 글자 크기에서 문서가 잘리지 않는다 | 설정 → 손쉬운 사용 → 더 큰 텍스트를 가장 크게 하고 문서·전사·플레이어를 연다. 글이 잘리거나 겹치지 않고, 출처 칩이 다음 줄로 넘어간다 | |
| 11 | P6-A5 | VoiceOver로 문서를 처음부터 끝까지 읽을 수 있다 | VoiceOver를 켜고 문서를 손가락 쓸기로 끝까지 읽는다. 제목은 "머리말", 강조 상자는 라벨(시험·과제·중요·참고) 먼저, 출처는 "출처, 12분 5초부터 듣기"로 읽힌다. 플레이어 버튼이 모두 이름으로 읽힌다 | |
| 12 | P6-A5 | 전사 목록을 직접 스크롤하면 5초 동안 따라가지 않는다 | 재생 중 전사를 손가락으로(Mac은 트랙패드와 마우스 휠로도) 스크롤한다. 스크롤이 멈춘 뒤 5초 동안은 현재 구간으로 돌아가지 않는다. Mac의 휠·트랙패드가 SwiftUI 스크롤 단계(interacting → idle)를 보고하는지 이 항목에서 확인한다 | |
| 13 | P6-A6 | 실제 서버에 로그인해 목록·문서·전사·재생이 된다 | 서명한 빌드로 실제 서버에 이메일로 로그인한다(native 토큰이 없는 서버는 API 토큰). 폴더를 바꾸고, 녹음을 열어 문서의 출처를 누르면 그 시각부터 재생되는지, 1시간 넘게 재생해도(접근 토큰 만료) 이어지는지 본다 | |
| 14 | P6-A6 | VoiceOver로 로그인부터 문서 읽기까지 간다 | VoiceOver만으로 로그인, 폴더 선택, 녹음 열기, 문서 읽기, 전사 탭, 재생까지 한다. 목록 줄은 "제목, 날짜, 길이, 상태"로 읽힌다 | |
| 15 | P6-A6 | iPad에서 문서와 전사가 나란히 보인다 | iPad 가로 화면에서 녹음을 열면 문서와 전사가 나란히 있고, 재생하면 전사가 따라간다 | |
| 16 | P6-A6 | UI 테스트가 시뮬레이터에서 통과한다 | `xcodebuild test -project apps/apple/Lectern.xcodeproj -scheme LecterniOS -destination 'platform=iOS Simulator,name=iPhone 17'`(픽스처 모드). 이 Mac은 CoreSimulator가 Xcode보다 오래돼 돌리지 못했다 | |
