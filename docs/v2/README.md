# Lectern v2 설계 문서

Lectern을 "강의 녹음 → 요약" 앱에서 **녹음(+PDF) → 구조화 문서** 플랫폼으로 개편하기 위한 설계 문서 묶음이다.

| 문서 | 내용 | 먼저 읽을 사람 |
|---|---|---|
| [ROADMAP.md](ROADMAP.md) | **결정 필요 사항(D1~D12)**, 단계별 계획(P0~P7)과 종료 기준, 병렬화, 리스크, 보류 목록 | 의사결정자, 모두 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 현재 상태, 시스템 구조, 모노레포, 데이터 모델 v2, API v2, 웹·네이티브, 계정, 캘린더, 검색, Ops·DX, 보안 | 구현 담당자 |
| [AI_HARNESS.md](AI_HARNESS.md) | AI 워커 파이프라인(단계, 영속 큐, 검증, 공급자 추상화, 비용, 템플릿, 평가) | 하네스 담당자 |

읽는 순서: ROADMAP의 결정 표 → ARCHITECTURE §2(현재 상태)와 §5(데이터 모델) → AI_HARNESS §2~§4.

표기 규칙: 문서는 한국어로 쓰고, 코드 식별자, 테이블·컬럼 이름, 단계 이름(`transcribe`, `verify` 등)은 영어로 쓴다.

이 문서들은 결정이 내려질 때마다 갱신한다. 큰 결정은 `docs/adr/`에 ADR로 남기고 여기서 링크한다.
