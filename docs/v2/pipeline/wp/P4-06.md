## 5. 단계

1. `ask/list-items.ts`
   ```ts
   import type { ListItemsSource } from "@lectern/ask";
   export const listItemsSource: ListItemsSource = async (access, args) => { … }
   ```
   - `args`는 `{ kind: "events" | "action_items"; from?: string; to?: string }`다. `from`·`to`는 `YYYY-MM-DD` 또는 ISO 8601이다. `Date.parse`가 실패하면 그 경계는 없는 것으로 본다. `to`가 날짜만이면 그날 끝(다음 날 0시 전)까지 포함한다. 시간대는 `Asia/Seoul`로 해석한다(날짜만 왔을 때 `+09:00`을 붙여 파싱).
   - 범위: `access`가 가리키는 워크스페이스에서, 그 사용자가 볼 수 있는 녹음(`VISIBLE_RECORDING_SQL`과 같은 조건)의 항목만. `access`가 녹음을 제한하면(녹음 한 건 범위의 물어보기) 그 녹음들만.
   - `events`: `status IN ('accepted','synced','suggested')`, `start_at`이 `[from, to]` 안. `start_at` 순, 최대 50개.
   - `action_items`: `status = 'open'`. `from`·`to`가 있으면 `due_at`이 그 안인 것만(마감 없는 것은 제외), 없으면 전부(마감 있는 것 먼저, 마감 순). 최대 50개.
   - 반환은 모델이 읽을 문자열이다. 한 줄에 하나.
     - 일정: `- [일정] 2026-10-27 15:00 중간고사 (녹음: 자료구조 7주차, 상태: 수락됨) #rec:<recording_id>`
     - 하루 종일: 시각 없이 날짜만.
     - 할 일: `- [할 일] 마감 2026-10-27 과제 3장 제출 (녹음: 자료구조 7주차) #rec:<recording_id>` (마감이 없으면 `마감 없음`)
     - 상태 표기: `suggested` → `제안`, `accepted` → `수락됨`, `synced` → `캘린더에 있음`.
     - 하나도 없으면 `해당 기간에 항목이 없습니다.`
     - 50개를 넘으면 마지막 줄에 `(이후 항목 생략)`.
   - 시각 표기는 `Asia/Seoul`의 `YYYY-MM-DD HH:mm`이다.
2. `ask/service.ts`: 의존성을 만드는 곳에 `listItems: listItemsSource`를 더한다. 플래그와 상관없이 넣는다(일정·할 일은 캘린더 플래그 없이도 있는 데이터다).

## 6. 테스트

`ask-list-items.test.ts` (행은 직접 넣는다. 기준 날짜를 고정하려면 `start_at`을 절대값으로 준다)

| 테스트 이름 | 준비 | 기대 |
|---|---|---|
| "events inside the range" | 10/20, 10/27, 11/5 일정. `from: "2026-10-26", to: "2026-11-01"` | 10/27 한 줄만 |
| "to is inclusive of the whole day" | 10/27 23:30 일정, `to: "2026-10-27"` | 포함 |
| "dismissed events are left out" | `dismissed` 일정 | 없다 |
| "action items: open only" | `open`, `done` | `open`만 |
| "action items without a due date" | 범위 없음 → 포함, 범위 있음 → 제외 | 그대로 |
| "private recordings of others" | B의 비공개 녹음의 일정, A가 호출 | 없다 |
| "recording-scoped access" | `access`가 녹음 1건으로 제한 | 그 녹음의 항목만 |
| "empty" | 항목 없음 | `해당 기간에 항목이 없습니다.` |
| "bad dates are ignored" | `from: "어제"` | 던지지 않고 경계 없이 동작 |
| "line format" | 일정 1개 | 줄이 `- [일정] 2026-10-27 15:00 중간고사 (녹음: 자료구조 7주차, 상태: 수락됨) #rec:`로 시작 |
| "service wires the tool" | 물어보기 서비스의 도구 목록(가짜 LLM이 받은 요청) | `list_items`가 들어 있다 |

- `AccessScope`의 필드 이름(사용자 id, 워크스페이스 id, 녹음 제한)은 확인하지 않았다. 타입을 읽고 맞춘다.
