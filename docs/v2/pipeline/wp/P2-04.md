## 1. 목표

녹음 상세의 문서 위에 "편집" 버튼을 둔다(D-P2-2). legacy 문서(`body`가 null)는 Markdown `<textarea>` + 미리보기, 구조화 문서는 블록의 **글자만** 고친다(블록 추가·삭제·순서 변경 없음, 출처 `sources`는 그대로). 저장은 `createDocumentVersion` + `If-Match`. 저장하면 버전이 1 늘고 "직접 수정" 표시가 붙는다. 412면 "다른 곳에서 바뀌었습니다" 대화상자에서 "다시 불러오기" 또는 "내 글 복사"를 고른다.

## 5. 단계

1. `edit-model.ts`:
   ```ts
   export interface EditableField { key: string; label: string; value: string; multiline: boolean }
   /** Text fields of the body in reading order. key = `${blockId}:${path}` (path: text | items.2 | term | definition | expression | explanation). */
   export function editableFields(body: DocumentBody): EditableField[]
   /** A copy of the body with the values applied. Blocks, sections, ids, sources and gaps are untouched. Unknown keys are ignored. */
   export function applyFields(body: DocumentBody, values: Record<string, string>): DocumentBody
   export const BLOCK_LABEL: Record<string, string> // paragraph: 단락, list: 목록, quote: 인용, term: 용어, formula: 수식, callout: 강조
   ```
   - 편집 대상: paragraph `text`; list `items[i].text`(항목마다 필드); quote `text`; term `term`·`definition`; formula `expression`·`explanation`(null이면 필드 만들지 않음); callout `text`. `gap`과 알 수 없는 블록은 건너뛴다.
   - `label` 예: `핵심 요약 · 단락`, `핵심 요약 · 목록 2번째 항목`(섹션 제목 + 블록 이름).
   - 빈 문자열로 바꾸는 것은 허용하지 않는다(저장 버튼에서 `비어 있는 칸이 있습니다.`로 막는다).
2. `queries.ts` — `useSaveDocument`:
   ```ts
   export function useSaveDocument(documentId: string, recordingId: string) {
     const api = useApi(); const qc = useQueryClient();
     return useMutation({
       mutationFn: (v: { body?: DocumentBody; markdown?: string; baseVersion: number }) =>
         api.createDocumentVersion(documentId, v.body !== undefined ? { body: v.body } : { markdown: v.markdown! }, v.baseVersion),
       onSuccess: () => { void qc.invalidateQueries({ queryKey: queryKeys.document(documentId) }); void qc.invalidateQueries({ queryKey: queryKeys.recording(recordingId) }); },
     });
   }
   ```
3. `DocumentEditor.tsx` — 속성 `{ doc: DocumentWithVersion; recordingId: string; onClose: () => void }`.
   - 상태: legacy면 `markdown`(처음 값 `doc.version.rendered_md`), 구조화면 `values`(`editableFields`의 key→value). `dirty` = 처음 값과 다름. `saving`.
   - 상단 줄: 제목 `<h2>` `문서 편집`, 배지 `버전 N 기준`, 버튼 `저장`(primary, 저장 중 `저장하는 중…`, 변경 없으면 `isDisabled`), `취소`. 단축키 안내 `<p className={uiStyles.hint}>` `⌘S(Windows는 Ctrl+S)로 저장, Esc로 닫기`.
   - legacy: `TextField`(`aria-label` `Markdown 본문`) + `TextArea` + 오른쪽(좁으면 아래) `미리보기` 영역(`<section aria-label="미리보기">` 안에 `<LegacyDocument markdown={markdown} />`). 첫 `<h2>`는 `문서 편집`이다.
   - 구조화: 섹션 제목을 `<h3>`로, 필드마다 `TextField` + `Label`(필드 `label`) + `TextArea`(`multiline`) 또는 `Input`. 맨 위 안내 `블록의 글자만 고칠 수 있습니다. 출처 표시와 순서는 그대로 유지됩니다.`
   - 저장: `api` 결과로 `toast`(`저장했습니다. 버전 N`)를 띄우고 `onClose()`. 오류가 `ApiClientError`이고 `status === 412`면 `conflict` 상태를 켜 `ConflictDialog`를 연다. 다른 오류는 `role="alert"`로 `errorMessage(err, "저장하지 못했습니다. 잠시 뒤 다시 시도하세요.")`.
   - 빈 칸 검사: 구조화에서 값이 `trim()` 빈 필드가 있으면 요청 없이 `비어 있는 칸이 있습니다.`(alert). legacy는 빈 본문도 허용하지 않는다: `본문이 비어 있습니다.`
   - 키보드: 편집기 최상위 `<div onKeyDown>`(React 합성 이벤트이므로 `on*` 속성 규칙과 무관)에서 `isImeComposing(e.nativeEvent)`이면 **아무것도 하지 않는다**. `(e.metaKey || e.ctrlKey) && e.key.toLowerCase() === "s"` → `preventDefault()` + 저장. `Escape` → dirty가 아니면 `onClose()`, dirty면 `나가기 확인` 대화상자를 연다. 편집 시작 시 첫 입력칸에 포커스, 닫힐 때 "편집" 버튼으로 포커스 복귀(`RecordingPage`가 `ref`).
   - 떠날 때 확인: `useBlocker({ shouldBlockFn: () => dirty, enableBeforeUnload: () => dirty, withResolver: true })`. 막히면 `ModalDialog`(`role="alertdialog"`, 제목 `저장하지 않은 수정이 있습니다`, 본문 `지금 나가면 고친 내용이 사라집니다.`, 버튼 `계속 수정`(닫기), `나가기`(`proceed()`)). `취소` 버튼과 Esc의 확인 대화상자는 같은 문구에 버튼 `계속 수정`/`수정 버리기`.
4. `ConflictDialog.tsx` — 속성 `{ isOpen, text, onReload, onClose }`. `ModalDialog role="alertdialog"` 제목 `다른 곳에서 바뀌었습니다`. 본문 `이 문서가 다른 곳에서 먼저 저장되었습니다. 지금 쓴 글은 아직 저장되지 않았습니다.` 버튼 `내 글 복사`(`navigator.clipboard.writeText(text)`, 성공 toast `내 글을 복사했습니다.`, 실패 toast `복사하지 못했습니다. 글을 직접 선택해 복사하세요.`)와 `다시 불러오기`(primary: 문서 쿼리 무효화 후 편집기를 닫고 toast `최신 버전을 불러왔습니다.`). 복사할 `text`: legacy는 `markdown`, 구조화는 모든 필드 값을 `\n\n`로 이은 문자열.
5. `DocumentPane.tsx` — 속성에 `onEdit?: () => void` 추가. `.docMeta` 끝에 `onEdit`이 있으면 `<Button size="sm" variant="ghost" icon="pencil" onPress={onEdit}>편집</Button>`. 아이콘 이름 `pencil`은 `ui/Icon.tsx`에 있다(새 아이콘을 만들지 않는다).
6. `RecordingPage.tsx` — `const [editing, setEditing] = useState(false)`. `panes.document`에서 `editing && doc.data`이면 `<DocumentEditor doc={doc.data} recordingId={rec.id} onClose={() => setEditing(false)} />`, 아니면 기존 `DocumentPane`에 `onEdit={() => setEditing(true)}`. 편집 중에는 `PlaybackProvider` 안에 있으므로 미리보기가 `usePlayback`을 써도 된다. 처리 중·실패 녹음은 편집 버튼이 없다(문서가 없다).
7. `edit.module.css` — 두 열 `.legacyGrid`(`grid-template-columns: minmax(0,1fr) minmax(0,1fr)`, 1280px 미만 한 열), `.fields`, `.toolbar`. 색은 토큰만(`styles.test.ts`).

## 10. 명세 작성자 메모

- `useBlocker`의 정확한 옵션 이름은 설치된 버전에서 확인하지 못했다(3절 마지막 지시). 다르면 BLOCKED로 보고한다.
- viewer 역할은 서버가 403을 준다. 화면에서 편집 버튼을 숨기는 규칙은 계약에 없어 하지 않는다(저장 시 오류 문구만).
- `GlobalShortcuts.tsx`의 한 글자 단축키가 `textarea`에서 꺼지는지 읽지 않았다. 구현 중 입력 칸에서 단축키가 가로채이면 그 파일(소유 경로 안)에서 입력 요소를 제외한다.
