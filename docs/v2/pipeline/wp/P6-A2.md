# P6-A2 LecternKit: API 클라이언트와 인증

> 등급: `careful` · 게이트: `apple` · 의존: `P6-A1` · 소유: `apps/apple/`
> (이 줄은 `pipeline.json`의 값과 같아야 한다.)

## 1. 목표

Apple 앱이 서버 API v2를 부르는 한 곳을 만든다. `packages/domain/openapi.json`에서 Swift 클라이언트를 생성하고, 그 위에 앱이 쓰는 얇은 래퍼(녹음 목록·상세·문서·전사)를 둔다. 토큰은 Keychain에 두고, 401을 받으면 refresh를 한 번 하고 다시 시도한다. 서버에 네이티브 토큰(P5-03)이 없어도 v1 API 토큰으로 동작한다.

## 2. 먼저 읽을 것

- 계약: `CONTRACTS.md` D-P6-7, D-P6-8, D-P5-4, D-P6-9
- 문서: `docs/v2/NATIVE.md` §3; `packages/domain/README.md`(동결 규칙: 모르는 블록 `type`은 무시)

## 5. 단계

1. 입력 복사: `scripts/pre-gate-openapi.sh`가 `../../packages/domain/openapi.json`을 `Packages/LecternKit/Sources/LecternKit/openapi.json`으로 복사한다(내용이 같으면 건드리지 않는다). `apps/apple/.gitignore`에 `Packages/LecternKit/Sources/LecternKit/openapi.json`을 더한다. 복사본도 생성 코드도 커밋하지 않는다.
2. `Package.swift`: 의존을 더한다.
   ```swift
   dependencies: [
       .package(url: "https://github.com/apple/swift-openapi-generator", from: "1.6.0"),
       .package(url: "https://github.com/apple/swift-openapi-runtime", from: "1.7.0"),
       .package(url: "https://github.com/apple/swift-openapi-urlsession", from: "1.0.0"),
   ],
   // target LecternKit:
   dependencies: [
       .product(name: "OpenAPIRuntime", package: "swift-openapi-runtime"),
       .product(name: "OpenAPIURLSession", package: "swift-openapi-urlsession"),
   ],
   plugins: [.plugin(name: "OpenAPIGenerator", package: "swift-openapi-generator")],
   ```
   버전은 `swift package resolve`가 받는 것으로 `Package.resolved`에 고정하고 그 파일을 커밋한다. 위 최소 버전이 없다고 나오면 실제로 있는 1.x의 최신으로 맞춘다.
3. `openapi-generator-config.yaml`
   ```yaml
   generate:
     - types
     - client
   accessModifier: internal
   filter:
     operations:
       - getMe
       - listWorkspaces
       - listFolders
       - listRecordings
       - getRecording
       - getTranscript
       - getDocument
       - listRecordingEvents
       - listRecordingActionItems
       - createUpload
       - getUpload
       - putUploadPart
       - completeUpload
       - abortUpload
       - getAssetContent
       - issueNativeToken
       - revokeNativeToken
   ```
   - `routes.ts`에 없는 operationId는 목록에서 뺀다(생성기가 모르는 이름을 오류로 처리한다).
   - **생성기가 문서를 처리하지 못하면**(지원하지 않는 스키마 구성, 진단 오류): 오류 메시지를 읽고 `filter`로 그 operation이나 스키마를 빼서 해결되는지 본다. 앱에 꼭 필요한 operation(위 목록의 앞 9개)을 뺄 수밖에 없으면 **멈추고 보고한다**(`BLOCKED_REASON`에 진단 전문). 손으로 쓴 클라이언트로 바꾸지 않는다(D-P6-7을 바꾸는 결정은 오케스트레이터와 사용자의 몫이다).
   - 생성된 타입은 `internal`이다. 앱은 4단계의 래퍼와 모델만 본다.
4. 래퍼
   ```swift
   public struct LecternAPI: Sendable {
       public init(serverURL: URL, auth: AuthProvider, session: URLSession = .shared)
       public func me() async throws -> Me
       public func workspaces() async throws -> [WorkspaceSummary]
       public func folders(workspaceID: String) async throws -> [Folder]
       public func recordings(workspaceID: String, folderID: String?, cursor: String?) async throws -> Page<RecordingSummary>
       public func recording(id: String) async throws -> RecordingDetail
       public func transcript(recordingID: String) async throws -> Transcript
       public func document(id: String) async throws -> Document
       public func assetContentRequest(assetID: String) async throws -> URLRequest     // authorised request for AVPlayer / downloads
   }
   public enum APIError: Error, Equatable { case unauthorized, forbidden, notFound, quotaExceeded(message: String), server(status: Int, code: String?, message: String?), transport(String), decoding(String) }
   ```
   - 모델(`Models/`)은 앱이 쓰는 필드만 가진 값 타입이다. 생성 타입에서 변환한다. 시각은 `Date`, 길이는 ms 정수.
   - `DocumentBlock`은 enum이다: `paragraph`, `heading`, `list`, `quote`, `term`, `formula`, `callout`, `gap`, 그리고 `unknown`. **모르는 `type`은 `unknown`으로 디코드하고 오류를 내지 않는다.** 블록의 출처(`sources`)는 `[SourceRef]`(구간 id, 시작·끝 ms, PDF 쪽).
   - 서버 오류 본문 `{ "error": { "code", "message" } }`를 읽어 `APIError`로 바꾼다. `quota_exceeded`는 서버의 한국어 문구를 그대로 싣는다.
5. 인증
   ```swift
   public protocol AuthProvider: Sendable {
       func authorize(_ request: inout URLRequest) async throws        // adds the credential header
       func refreshAfterUnauthorized() async throws -> Bool             // true when a retry makes sense
       func signOut() async
   }
   public protocol TokenStore: Sendable { func read(_ key: String) -> String?; func write(_ value: String, for key: String) -> Bool; func delete(_ key: String) }
   public final class KeychainTokenStore: TokenStore     // kSecClassGenericPassword, service "com.qucord.lectern", access group from init, AfterFirstUnlockThisDeviceOnly
   public final class InMemoryTokenStore: TokenStore
   public actor ApiTokenProvider: AuthProvider           // v1 API token: header "X-Lectern-Token". refreshAfterUnauthorized() returns false
   public actor NativeTokenProvider: AuthProvider        // D-P5-4: "Authorization: Bearer <access>"; refresh rotates the pair
   ```
   - `NativeTokenProvider`: `signIn(email:password:deviceName:)`이 `POST /api/v2/auth/native/token`(`grant_type: "password"`)을 부르고 access·refresh를 저장한다. `refreshAfterUnauthorized()`는 `grant_type: "refresh_token"`을 부른다. **동시에 여러 요청이 401을 받아도 refresh는 한 번만 일어난다**(actor 안에서 진행 중인 `Task`를 공유). refresh가 401이면 저장된 토큰을 지우고 `false`. 새 쌍은 Keychain에 **쓴 뒤에** 메모리에 반영한다(회전된 refresh를 잃으면 로그인이 끊긴다).
   - `AuthMiddleware`(생성 클라이언트의 `ClientMiddleware`): 요청에 `authorize`를 적용하고, 응답이 401이면 `refreshAfterUnauthorized()`가 `true`일 때 **한 번만** 다시 보낸다. 본문이 스트림인 요청(파트 업로드)은 다시 보내지 않고 401을 그대로 돌려준다.
   - Keychain 접근 그룹은 `init(accessGroup: String?)`로 받는다(앱이 `$(AppIdentifierPrefix)com.qucord.lectern`을 넘긴다). 테스트는 `InMemoryTokenStore`만 쓴다.
6. 테스트 픽스처: `packages/domain/test/fixtures.ts`의 유효 예시에서 `RecordingPage`, `RecordingDetail`, `Transcript`, `DocumentWithVersion`, `Me`, 오류 본문을 JSON 파일로 뽑아 `Tests/LecternKitTests/Fixtures/`에 커밋한다. 뽑는 한 줄 스크립트를 `Fixtures/README.md`에 적는다(다시 뽑을 수 있게). 문서 픽스처에는 모르는 블록(`{"type":"future_block","x":1}`)을 하나 **손으로 더한다**.

## 8. 하지 않는 것

- 업로드 큐(`P6-A3`), 화면(`P6-A5`, `P6-A6`).
- Google·Apple 로그인으로 네이티브 토큰을 받는 흐름(서버에 없다. P5-03 8절).
- 생성 코드를 손으로 고치거나 커밋하지 않는다.

## 9. 끝났다는 기준

- [ ] 6절의 테스트가 통과한다
- [ ] 게이트가 통과한다(시뮬레이터·macOS 빌드에 생성 클라이언트가 들어간다)
- [ ] 복사한 `openapi.json`과 생성 코드가 커밋되지 않는다
- [ ] 토큰이 로그와 `UserDefaults`에 없다

## 10. 명세 작성자 메모

- `swift-openapi-generator`가 이 저장소의 `openapi.json`을 처리하는지는 **확인하지 않았다.** zod에서 만든 문서라 `anyOf`·nullable·판별 유니온이 섞여 있다. 3단계의 멈춤 조건이 그래서 있다. 이 작업이 P6의 가장 큰 불확실성이다(STATUS에 적었다).
- 패키지 의존을 받으려면 네트워크가 필요하다(GitHub). 게이트가 오프라인에서 돌면 실패한다.
- 플러그인은 Xcode 빌드에서 "신뢰하지 않는 플러그인" 확인을 요구할 수 있다. `gate.sh`의 `xcodebuild`에 `-skipPackagePluginValidation`을 더해야 하면 그 한 줄을 고친다(`gate.sh`는 `apps/apple/` 안이라 소유 범위다).
