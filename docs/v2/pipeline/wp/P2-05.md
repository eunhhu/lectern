# P2-05 웹: 공유 UI

> 등급: `basic` · 게이트: `full` · 의존: `P2-02` · 소유: `apps/web/`
> (이 줄은 `pipeline.json`의 값과 같아야 한다.)

## 1. 목표

녹음 상세의 "녹음 작업" 메뉴에 "공유…"를 넣고, 대화상자에서 공유 링크를 만들고(포함 범위, 만료, 비밀번호), 만든 직후 링크를 복사하고, 회수한다. 설정에 "공유 링크" 구역을 두어 내 링크 목록을 보고 회수한다. 링크 원문은 만든 직후에만 보이며 화면이 그렇게 안내한다.

## 5. 단계

1. `ApiClient` (이름은 operationId 그대로):
   ```ts
   listShareLinks(workspaceId: WorkspaceId, targetId?: string): Promise<ShareLinkPage>;
   createShareLink(body: CreateShareLinkRequest): Promise<CreatedShareLink>;
   revokeShareLink(shareLinkId: string): Promise<void>;
   ```
   (`ShareLinkPage` 타입도 `types.ts`에서 재수출.)
2. `http/client.ts` 한 줄씩: `listShareLinks: (ws, targetId) => call("listShareLinks", { query: { workspace_id: ws, ...(targetId ? { target_id: targetId } : {}), limit: 200 } })`, `createShareLink: (body) => call("createShareLink", { body })`, `revokeShareLink: (id) => call("revokeShareLink", { params: { share_link_id: id } })`.
3. `fixture/client.ts` — 클로저 변수 `const shareLinks: ShareLinkDto[] = []`, `let shareSeq = 0`. `create`: `id = "shl_fx" + ++shareSeq`, `has_password = Boolean(body.password)`, `revoked_at: null`, `created_by = data.me.id`, `url = "https://lectern.example/s/fixture-token-" + shareSeq`(`z.url()`이므로 올바른 URL) 반환 `{ link, url }`. `list`: 회수되지 않은 것만, `target_id` 필터, `page(...)` 헬퍼. `revoke`: 없으면 `notFound`, 있으면 `revoked_at`을 채워 제거.
4. `queries.ts`: `queryKeys.shareLinks = (ws: string) => ["share-links", ws] as const`. `useShareLinks(ws, targetId?)`는 `useQuery`(`queryKey: [...queryKeys.shareLinks(ws), targetId ?? "all"]`, `queryFn: () => api.listShareLinks(ws, targetId).then(p => p.items)`). 두 변경 훅은 `useMutation`, `onSettled`에서 `qc.invalidateQueries({ queryKey: queryKeys.shareLinks(ws) })`.
5. `ShareLinkRow.tsx` — 속성 `{ link: ShareLinkDto; title?: string; ws: string }`. 줄: (제목이 있으면 제목), 배지/문구 `전사 포함`(scope.transcript), `오디오 포함`(scope.audio), 둘 다 아니면 `문서만`; `비밀번호 있음`(has_password); 만료 `만료 없음` 또는 `YYYY. M. D. 만료`(`lib/format.ts`의 날짜 포맷이 있으면 그것, 없으면 `toLocaleDateString("ko-KR")`); 만든 날. 오른쪽 버튼 `회수`(`variant="dangerText"`, `aria-label={`공유 링크 회수: ${title ?? "이 녹음"}`}`). 누르면 `ModalDialog role="alertdialog"` 제목 `공유 링크를 회수할까요?`, 본문 `회수하면 이 링크로는 더 이상 열 수 없습니다. 되돌릴 수 없습니다.`, 버튼 `취소`, `회수`(danger). 성공 toast `공유 링크를 회수했습니다.`, 실패 `toastError("공유 링크를 회수하지 못했습니다.", err)`.
6. `ShareDialog.tsx` — 속성 `{ recording: Recording; isOpen: boolean; onOpenChange(open: boolean): void }`. `ModalDialog` 제목 `공유`, `size="form"`. 내용(위에서 아래):
   - 구역 `<h3>` `새 공유 링크`: 설명 `링크를 아는 사람은 로그인 없이 문서를 볼 수 있습니다.` 체크박스(`CheckboxField`) `전사 포함`, `오디오 포함`(기본 둘 다 해제). `SelectField` `만료`: `만료 없음`(기본), `1일 뒤`, `7일 뒤`, `30일 뒤`. 비밀번호 `TextField`(`type="password"`, `autoComplete="new-password"`, 라벨 `비밀번호 (선택)`, 힌트 `8자 이상. 비워 두면 링크만 알면 열립니다.`). 버튼 `링크 만들기`(primary, 진행 중 `만드는 중…`).
   - 검사: 비밀번호를 입력했는데 8자 미만이면 요청 없이 `role="alert"` `비밀번호는 8자 이상이어야 합니다.`
   - 요청: `{ target_type: "recording", target_id: recording.id, scope: { transcript, audio }, expires_at: days ? new Date(Date.now() + days * 86_400_000).toISOString() : null, password: password || null }`.
   - 만든 직후: 같은 자리에 `<div role="status">`로 안내 `이 링크는 지금만 볼 수 있습니다. 닫으면 다시 확인할 수 없으니 지금 복사하세요.`, 읽기 전용 `TextField`(라벨 `공유 링크`, `isReadOnly`, 값 = `url`, 포커스), 버튼 `링크 복사`(`navigator.clipboard.writeText(url)` 성공 toast `링크를 복사했습니다.`, 실패 toast `복사하지 못했습니다. 링크를 직접 선택해 복사하세요.`). 이 `url`은 컴포넌트 상태에만 두고 `localStorage`·쿼리 캐시·URL에 넣지 않는다. 대화상자를 닫으면 상태를 지운다.
   - 구역 `<h3>` `만든 링크`: `useShareLinks(rec.workspace_id, rec.id)`의 `ShareLinkRow` 목록, 비었으면 `이 녹음의 공유 링크가 없습니다.` 그 아래 힌트 `이미 만든 링크의 주소는 다시 볼 수 없습니다. 필요하면 회수하고 새로 만드세요.`
   - 서버 오류는 `role="alert"`에 `errorMessage(err, "링크를 만들지 못했습니다. 잠시 뒤 다시 시도하세요.")`.
7. `RecordingPage.tsx` — 메뉴(`녹음 작업`)에 `<MenuItem id="share">` `공유…`(아이콘 `send`)를 `태그…` 뒤에 넣는다. `onAction`이 `share`면 `setShareOpen(true)`, 나머지는 기존 `setAction`. `<ShareDialog recording={rec} isOpen={shareOpen} onOpenChange={setShareOpen} />`를 `dialogs` 옆에 렌더(처리 중·실패 화면의 `dialogs`와는 별개로 `return`되는 세 곳 모두에서 공유하려면 `dialogs` 변수에 함께 넣는다).
8. `SettingsPage.tsx` — `SECTIONS`에 항목 추가(기기 앞). `ShareLinks` 구역: `<section id="share-links" className={s.section} aria-labelledby="set-share-links">`, `<h2>` `공유 링크`, 설명 `링크 주소는 만든 직후에만 볼 수 있습니다.`, `useShareLinks(ws)` 목록(`ShareLinkRow`에 `title`은 `useRecordings(ws)`에서 `target_id`로 찾은 녹음 제목, 문서 대상이면 `문서 링크`), 비었으면 `만든 공유 링크가 없습니다.` 워크스페이스 id는 `WorkspaceSection`이 쓰는 훅과 같은 것(`useWorkspace()`)을 쓴다.

## 10. 명세 작성자 메모

- v1에서 옮겨 온 공개 강의는 설정의 "공유 링크" 목록에 `shl_…` 링크로 나타난다(서버 `listShareLinks`). 회수하면 서버가 그 강의를 비공개로 돌린다(P2-02).
- 회수 후 404 문구는 P2-02가 옛 처리기로 넘겨 나오는 텍스트다. e2e는 상태 코드 404만 단언한다.
- server e2e의 서버는 `LECTERN_BASE_URL=http://127.0.0.1:4175`라 응답 `url`이 그 주소다. `playwright.config.ts`의 `baseURL`과 같다.
- `useWorkspace()`의 반환 모양과 `formatDate` 계열 함수 이름은 읽지 않았다. 구현 중 `SettingsPage.tsx`의 `WorkspaceSection`을 보고 맞춘다.
