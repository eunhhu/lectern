# P6-A7 iOS 녹음 표면

> 등급: `careful` · 게이트: `apple` · 의존: `P6-A4`, `P6-A6` · 소유: `apps/apple/`
> (이 줄은 `pipeline.json`의 값과 같아야 한다.)

## 1. 목표

iPhone에서 앱을 열지 않고 녹음한다. 제어 센터·잠금 화면·동작 버튼의 컨트롤이나 Siri·단축어로 녹음을 시작하면 Live Activity(잠금 화면과 Dynamic Island)에 경과 시간이 보이고, 거기서 일시정지·재개·"중요" 표시·정지를 한다. 화면이 꺼져도 녹음은 이어지고, 정지하면 파일이 업로드 대기열로 들어간다. 앱 안에도 같은 녹음 화면이 있다.

## 5. 단계

1. `RecordingActivityAttributes`
   ```swift
   public struct RecordingActivityAttributes: ActivityAttributes {
       public struct ContentState: Codable, Hashable {
           public var phase: Phase                    // recording, paused, uploading, finished
           public var startedAt: Date                 // adjusted so that Text(timerInterval:) shows recorded time without pauses
           public var pausedElapsedMs: Int?           // set while paused: the frozen elapsed time
           public var markerCount: Int
           public var silenceWarning: Bool
       }
       public var title: String                       // "새 녹음" or the folder name
   }
   public enum Phase: String, Codable, Hashable { case recording, paused, uploading, finished }
   ```
   경과 시간 표시 규칙(순수 함수로 뺀다): `recording`이면 `Text(timerInterval: startedAt...distantFuture, countsDown: false)`, `paused`면 고정 글자(`pausedElapsedMs`를 `분:초`로). 재개할 때 `startedAt = 지금 − 녹음된 시간`으로 다시 잡는다.
   ```swift
   public func timerStart(now: Date, recordedMs: Int) -> Date
   ```
2. `RecordingActivityController`(프로토콜): `start(attributes:state:)`, `update(state:)`, `end(state:dismissAfter:)`. 실제 구현은 `Activity<RecordingActivityAttributes>`를 쓴다. 테스트는 호출을 기록하는 가짜를 쓴다. Live Activity를 켤 수 없으면(`ActivityAuthorizationInfo().areActivitiesEnabled == false`) 녹음은 그대로 하고 활동만 건너뛴다.
3. `RecordingSession`(actor, 앱 전체에 하나: `RecordingSession.shared`)
   ```swift
   public actor RecordingSession {
       public init(makeRecorder: @escaping @Sendable () -> Recorder, activity: RecordingActivityController, enqueue: @escaping @Sendable (RecordingResult, RecordingDraft) async throws -> Void, now: @escaping @Sendable () -> Date)
       public var isActive: Bool { get }
       public func start(draft: RecordingDraft) async throws
       public func pause() async; public func resume() async
       public func addMarker() async -> Int?
       public func stop() async throws -> RecordingResult?
       public nonisolated var states: AsyncStream<RecordingActivityAttributes.ContentState> { get }
   }
   public struct RecordingDraft: Sendable, Equatable { public var workspaceID: String; public var folderID: String?; public var title: String? }
   ```
   - `start`: 이미 녹음 중이면 아무것도 하지 않는다(두 번째 녹음을 만들지 않는다). 마이크 권한이 없으면 `RecordingError.microphoneDenied`(`"마이크 권한이 필요합니다. 설정에서 Lectern의 마이크를 켜 주세요."`).
   - 상태가 바뀔 때(시작·일시정지·재개·마커·무음 경고 켜짐/꺼짐)만 Live Activity를 갱신한다. **레벨 값으로 갱신하지 않는다**(갱신 횟수 제한에 걸린다).
   - `stop`: 녹음기를 멈추고 → `enqueue(result, draft)`(→ `UploadQueue.enqueue`: 파일을 App Group 컨테이너로 옮기고 `recordedAt = result.startedAt`, 마커 포함) → Live Activity를 `uploading`으로 바꾼 뒤 4초 뒤 끝낸다(처리 진행 표시는 P6-A11이 잇는다). `enqueue`가 실패해도 녹음 파일은 지우지 않고 오류를 던진다.
   - 2초보다 짧은 녹음은 올리지 않고 파일을 지운다(실수로 누른 경우). `stop`은 `nil`을 돌려준다.
4. 인텐트(`LecternIntents`)
   - `StartRecordingIntent: AudioRecordingIntent` — 제목 `녹음 시작`. `perform()`이 `RecordingSession.shared.start(draft:)`를 부른다. 기본 워크스페이스·폴더는 App Group `UserDefaults`(`group.com.qucord.lectern`)의 `default_workspace_id`에서 읽는다(앱이 로그인 때 써 둔다). 없으면 `로그인이 필요합니다. Lectern 앱을 열어 로그인해 주세요.`로 실패한다.
   - `StopRecordingIntent`(`녹음 정지`), `PauseResumeIntent`(`일시정지/재개`), `AddMarkerIntent`(`중요 표시`): `LiveActivityIntent`를 따른다(앱 프로세스에서 실행돼야 녹음기에 닿는다). 녹음 중이 아니면 아무것도 하지 않고 성공한다.
   - `LecternShortcuts`: 문구 `"\(.applicationName)(으)로 녹음 시작"`, `"\(.applicationName) 녹음 정지"`, `"\(.applicationName) 중요 표시"`.
5. 위젯 확장
   - `RecordingLiveActivity`: `ActivityConfiguration(for: RecordingActivityAttributes.self)`. 잠금 화면: 제목, 경과 시간, 상태 글자(`녹음 중` / `일시정지됨` / `올리는 중`), 버튼 세 개(`일시정지`·`재개`, `중요`, `정지`. `Button(intent:)`). 무음 경고가 켜지면 `소리가 들리지 않습니다` 한 줄. Dynamic Island: compact 왼쪽 녹음 점, 오른쪽 경과 시간. minimal 녹음 점. expanded: 위와 같은 내용. 녹음 표시는 색과 함께 글자·아이콘으로 한다.
   - `RecordingControl: ControlWidget` — 토글 컨트롤 `녹음`(켜면 `StartRecordingIntent`, 끄면 `StopRecordingIntent`). 상태는 App Group `UserDefaults`의 `recording_active`(세션이 써 둔다)에서 읽는다.
   - `LecternWidgetsBundle`에 둘을 더하고 P6-A1의 자리 채움 위젯을 지운다.
6. 앱 안: 라이브러리의 큰 녹음 버튼 → `RecordScreen`(경과 시간, 레벨 막대, `일시정지`, `중요`, `정지`). 레벨 막대의 접근성 값은 `입력 레벨 <0~100>`이고, 화면에 `녹음 중`을 글자로 보인다. 정지하면 대기열 시트를 보인다.
7. `MANUAL_CHECKS.md`에 행(전부 실제 iPhone)
   - 제어 센터 컨트롤로 녹음을 시작·정지한다(앱을 열지 않는다)
   - 동작 버튼에 지정해 녹음을 시작한다
   - 잠금 화면에서 3시간 녹음 → 정지 → 업로드 → 서버에 문서가 생긴다
   - Dynamic Island의 compact·expanded·minimal 표시와 버튼 동작
   - 녹음 중 전화가 오면 일시정지되고 Live Activity가 `일시정지됨`으로 바뀐다
   - Live Activity가 꺼져 있어도(설정) 녹음이 된다
   - Siri로 "Lectern으로 녹음 시작"

## 10. 명세 작성자 메모

- `AudioRecordingIntent`·`ControlWidget`·`LiveActivityIntent`의 정확한 요구 사항(예: `AudioRecordingIntent`는 녹음 시작 때 Live Activity를 반드시 띄워야 한다)은 SDK 문서와 선언을 기준으로 한다. 이 명세의 타입 모양이 SDK와 맞지 않으면 SDK를 따르고 `DEVIATIONS`에 적는다.
- 인텐트가 앱 프로세스에서 도는지, 확장 프로세스에서 도는지에 따라 `RecordingSession.shared`에 닿는 방법이 달라진다. `LiveActivityIntent`는 앱 프로세스에서 실행된다는 전제로 썼다. 컨트롤(`ControlWidget`)의 인텐트도 `AudioRecordingIntent`라서 앱을 깨워 실행된다. 이 전제가 틀리면 멈추고 보고한다.
- 처리 진행을 같은 Live Activity로 잇는 것(NATIVE §4)은 P6-A11에서 별도 활동(`ProcessingActivityAttributes`)으로 한다. 녹음 활동은 정지 4초 뒤 끝난다.
