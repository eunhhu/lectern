# P6-A4 RecorderKit

> 등급: `careful` · 게이트: `apple` · 의존: `P6-A1` · 소유: `apps/apple/`
> (이 줄은 `pipeline.json`의 값과 같아야 한다.)

## 1. 목표

iOS와 macOS가 함께 쓰는 녹음 엔진을 만든다. 마이크 소리를 AAC(m4a) 파일로 쓰고, 입력 레벨을 알려 주고, 소리가 계속 없으면 경고하고, 일시정지·재개와 "중요" 마커를 지원하고, 전화 같은 방해와 이어폰 연결 변화에 대응한다. 핵심 규칙(상태 전이, 마커 시각 계산, 무음 판정)은 오디오 장치 없이 단위 테스트된다.

## 5. 단계

1. `RecorderState.swift`
   ```swift
   public enum RecorderState: Equatable, Sendable { case idle, recording, paused(reason: PauseReason), stopping, finished, failed(message: String) }
   public enum PauseReason: Equatable, Sendable { case user, interruption, routeLost }
   public enum RecorderEvent: Equatable, Sendable { case start, pause, resume, stop, interruptionBegan, interruptionEnded(shouldResume: Bool), routeLost, routeRestored, sinkFailed(String), finishedWriting }
   public func reduce(_ state: RecorderState, _ event: RecorderEvent) -> RecorderState
   ```
   전이 표(표에 없는 조합은 **상태를 바꾸지 않는다**)

   | 상태 | 사건 | 다음 상태 |
   |---|---|---|
   | `idle` | `start` | `recording` |
   | `recording` | `pause` | `paused(.user)` |
   | `recording` | `interruptionBegan` | `paused(.interruption)` |
   | `recording` | `routeLost` | `paused(.routeLost)` |
   | `paused(.user)` | `resume` | `recording` |
   | `paused(.interruption)` | `interruptionEnded(shouldResume: true)` | `recording` |
   | `paused(.interruption)` | `interruptionEnded(shouldResume: false)` | `paused(.user)` (사용자가 직접 재개해야 한다) |
   | `paused(.interruption)` | `resume` | `recording` |
   | `paused(.routeLost)` | `routeRestored` 또는 `resume` | `recording` |
   | `recording`, `paused(*)` | `stop` | `stopping` |
   | `stopping` | `finishedWriting` | `finished` |
   | `recording`, `paused(*)`, `stopping` | `sinkFailed(m)` | `failed(m)` |

   사용자가 일시정지한 상태(`paused(.user)`)에서는 `interruptionEnded`와 `routeRestored`가 와도 **재개하지 않는다.**
2. `RecordingClock.swift`
   ```swift
   public struct RecordingClock: Sendable {
       public init()
       public mutating func start(at t: TimeInterval)
       public mutating func pause(at t: TimeInterval)
       public mutating func resume(at t: TimeInterval)
       public func elapsedMs(at t: TimeInterval) -> Int      // recorded audio so far, pauses removed
   }
   ```
   마커 시각은 `elapsedMs(at: 지금)`이다. 일시정지 중에 누른 마커는 일시정지 시작 시점의 값이다. 시간이 거꾸로 가는 입력(`t`가 이전보다 작음)은 무시한다. 실제 녹음에서는 벽시계 대신 **쓴 프레임 수 ÷ 샘플레이트**를 쓴다(`Recorder`가 그렇게 한다). 이 타입은 UI의 경과 시간 표시와 테스트용이다.
3. `LevelMeter.swift`
   ```swift
   public func dbfs(samples: UnsafeBufferPointer<Float>) -> Float          // RMS in dBFS, floor -120
   public func normalizedLevel(dbfs: Float) -> Float                       // 0...1, -60 dB → 0, 0 dB → 1, clamped
   public struct SilenceDetector: Sendable {
       public init(thresholdDb: Float = -50, seconds: Double = 20)
       public mutating func feed(dbfs: Float, duration: Double) -> Bool    // true while the warning should show
   }
   ```
   무음 경고는 임계값 아래가 `seconds` 이상 이어지면 켜지고, 임계값 위의 버퍼가 한 번 오면 꺼진다. 일시정지 중의 시간은 세지 않는다.
4. `AudioSink`와 `AudioInput`
   ```swift
   public protocol AudioSink: Sendable { func open(url: URL, sampleRate: Double, channels: Int) throws; func write(_ buffer: AVAudioPCMBuffer) throws; func close() throws; var framesWritten: Int64 { get } }
   public protocol AudioInput: AnyObject, Sendable { var format: AVAudioFormat { get }; func start(onBuffer: @escaping @Sendable (AVAudioPCMBuffer) -> Void) throws; func stop() }
   ```
   - 실제 싱크: `AVAudioFile(forWriting:settings:)`, 설정 `kAudioFormatMPEG4AAC`, 1채널, 샘플레이트 44,100(기존 macOS 앱의 값이 다르면 그 값), 비트레이트 64kbps(기존 값이 있으면 그 값). 확장자 `.m4a`.
   - 실제 입력: `AVAudioEngine`의 `inputNode.installTap(onBus: 0, bufferSize: 4096, format: nil)`. 입력 형식이 파일 형식과 다르면 `AVAudioConverter`로 바꾼다.
   - 디스크 여유가 200MB 아래면 `open`이 던진다(`"저장 공간이 부족해 녹음을 시작할 수 없습니다."`).
5. `Recorder`(actor)
   ```swift
   public actor Recorder {
       public init(input: AudioInput, sink: AudioSink, directory: URL)
       public private(set) var state: RecorderState
       public func start() throws -> URL                   // file URL inside `directory`, name "rec-<yyyyMMdd-HHmmss>.m4a"
       public func pause(); public func resume(); public func stop() async throws -> RecordingResult
       public func addMarker(label: String? = nil) -> Int  // returns at_ms
       public func handle(_ event: RecorderEvent)          // interruptions and route changes from the coordinator
       public nonisolated var levels: AsyncStream<Float> { get }           // normalized, at most 10 per second
       public nonisolated var silenceWarning: AsyncStream<Bool> { get }
   }
   public struct RecordingResult: Sendable, Equatable { public let fileURL: URL; public let durationMs: Int; public let markers: [RecordedMarker]; public let startedAt: Date }
   public struct RecordedMarker: Sendable, Equatable, Codable { public let atMs: Int; public let label: String? }
   ```
   - 일시정지 중에는 버퍼를 **쓰지 않는다**(파일에 무음을 넣지 않는다). 그래서 파일의 길이 = 일시정지를 뺀 시간이고, 마커의 `atMs` = `framesWritten × 1000 ÷ 샘플레이트`다. 서버가 받는 마커 시각과 오디오가 어긋나지 않는다.
   - `stop()`은 싱크를 닫은 뒤 `finished`가 된다. `failed`면 그때까지 쓴 파일은 지우지 않는다(복구할 수 있게).
6. `SessionCoordinator`(`#if os(iOS)`): 카테고리 `.playAndRecord`, 모드 `.default`, 옵션 `[.allowBluetoothHFP, .defaultToSpeaker]`(SDK에 `.allowBluetoothHFP`가 없으면 `.allowBluetooth`). `AVAudioSession.interruptionNotification` → `interruptionBegan` / `interruptionEnded(shouldResume:)`, `routeChangeNotification`(이유 `.oldDeviceUnavailable`) → `routeLost`, (`.newDeviceAvailable`) → `routeRestored`. 알림을 `Recorder.handle`로 넘기는 일만 한다.
7. `MANUAL_CHECKS.md`에 행: "전화가 오면 일시정지되고 끝나면 재개를 묻는다", "AirPods를 빼면 일시정지된다", "화면을 끈 채 3시간 녹음 뒤 파일 길이가 맞다", "무음 20초에 경고가 뜬다".

## 10. 명세 작성자 메모

- "일시정지 중에는 파일에 쓰지 않는다"는 이 명세의 결정이다. 벽시계 기준으로 마커를 찍으면 서버의 전사 시각과 어긋난다.
- `AVAudioSession`의 옵션 이름은 SDK 버전에 따라 바뀌었다. 컴파일 오류가 나면 SDK 헤더의 현재 이름을 쓴다.
- `AVAudioFile`의 AAC 쓰기가 긴 녹음에서 안정적인지는 기기 확인 항목이다.
