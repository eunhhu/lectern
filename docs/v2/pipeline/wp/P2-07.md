# P2-07 웹: Pretendard 직접 호스팅

> 등급: `basic` · 게이트: `full` · 의존: `P0-01` · 소유: `apps/web/`
> (이 줄은 `pipeline.json`의 값과 같아야 한다.)

## 1. 목표

새 웹 앱이 Pretendard를 CDN 없이 자기 빌드 산출물에서 싣는다(D-P2-7). 미병합 브랜치 `claude/xenodochial-hamilton-b49ae7`의 글꼴 파일을 `apps/web/src/styles/fonts/pretendard/`로 가져오고, `global.css`가 `@font-face` 묶음을 불러온다. 빌드하면 woff2가 해시 붙은 이름으로 `dist/assets`에 들어가고, 화면 로드 중 외부 오리진 요청이 0건이다.

- 계약: `CONTRACTS.md` D-P2-7
- 레시피: `RECIPES.md` R8(CSS는 토큰만), R9
- 코드:
  - `apps/web/src/styles/global.css` — 맨 위 `@import "@lectern/design-tokens/tokens.css";`

  - `apps/web/scripts/serve.ts` — `PREVIEW_CSP`의 `font-src 'self'`
  - `apps/web/test/styles.test.ts` — `src/**/*.css`의 색 리터럴·`var()` 검사(글꼴 CSS도 통과해야 한다)
  - `apps/web/README.md` — "Pretendard를 싣지 않았다" 문단(168줄 근처)과 "남은 일" 9번

## 5. 단계

1. 파일 가져오기. 저장소 루트에서 아래를 그대로 실행한다(`git checkout <브랜치> -- <경로>`는 `apps/server/assets/…`에 만들어 소유 밖을 건드리므로 쓰지 않는다. `git show`로 내용만 꺼낸다).
   ```bash
   B=claude/xenodochial-hamilton-b49ae7
   SRC=apps/server/assets/pretendard
   DEST=apps/web/src/styles/fonts/pretendard
   mkdir -p "$DEST/woff2-dynamic-subset"
   git show "${B}:${SRC}/LICENSE.txt" > "$DEST/LICENSE.txt"
   git show "${B}:${SRC}/pretendardvariable-dynamic-subset.css" > "$DEST/pretendard.css"
   for n in $(seq 0 91); do
     git show "${B}:${SRC}/woff2-dynamic-subset/PretendardVariable.subset.${n}.woff2" > "$DEST/woff2-dynamic-subset/PretendardVariable.subset.${n}.woff2"
   done
   ls "$DEST/woff2-dynamic-subset" | wc -l   # 92
   git status --short apps/server                # must print nothing
   ```
   `${B}:${SRC}`처럼 중괄호를 꼭 쓴다(zsh는 `$B:`를 수정자로 읽는다). woff2 개수가 92가 아니면 3절 `ls-tree` 목록을 보고 번호를 맞춘다.
2. `global.css` — 첫 줄 `@import "@lectern/design-tokens/tokens.css";` **바로 아래**에 `@import "./fonts/pretendard/pretendard.css";`를 넣는다(`@import`는 다른 규칙보다 앞에 있어야 한다). 다른 줄은 건드리지 않는다.
3. 빌드해 본다: `cd apps/web && bun scripts/build.ts --out /tmp/p2-07-dist`(임시 경로는 스크래치 디렉터리를 써도 된다). 확인할 것: `assets/`에 `PretendardVariable.subset.N-<해시>.woff2`가 92개, CSS 산출물에 `font-display:swap`과 `Pretendard Variable`이 있고 `url(/app/assets/PretendardVariable.subset…`로 가리킨다. 만약 Bun이 woff2를 `data:`로 인라인하거나 원래 상대경로를 남기면 멈추고 보고한다(10절).
4. 테스트 두 개와 e2e를 6절대로 쓴다.
5. `README.md`: 168줄 근처 "Pretendard를 싣지 않았다" 문단을 `**Pretendard는 직접 호스팅한다.** apps/web/src/styles/fonts/pretendard/(OFL 라이선스 포함)를 global.css가 @font-face로 불러오고, 빌드가 woff2를 해시 이름으로 dist/assets에 넣는다. CDN을 쓰지 않는다.`로 바꾸고, "남은 일" 9번에서 `Pretendard 직접 호스팅 병합 후 @font-face, `를 지운다.

## 10. 명세 작성자 메모

- 카탈로그는 "토큰의 글꼴 스택 맨 앞에 둔다"고 하지만, 토큰 스택은 이미 `"Pretendard Variable"`로 시작한다(`packages/design-tokens/dist/tokens.css`). 토큰은 소유 밖이라 바꾸지 않고 `@font-face`만 더한다.
- Bun 번들러가 CSS의 `url(*.woff2)`를 어떻게 처리하는지(해시 파일로 내보내는지, 인라인하는지)는 실행해 보지 못했다. 5단계 3번에서 확인하고 다르면 BLOCKED로 보고한다.
- 글꼴 파일이 92개·약 3MB라 저장소가 커진다. 브라우저는 `unicode-range`에 맞는 조각만 내려받는다.
- 모든 `.woff2`는 이진 파일이므로 커밋 시 줄 끝 변환이 없는지 `git diff --stat`으로 확인한다.
