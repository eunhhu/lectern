## 1. 목표

`createShareLink`·`updateShareLink`·`revokeShareLink`를 구현하고(D-P2-3), 공개 페이지 `/s/:token`을 `apps/server/src/share-page.ts`가 새 `share_link` 행에서 그린다. 비밀번호 링크는 폼 POST로 확인하고 링크 전용 HttpOnly 쿠키를 준다. 확인은 링크·IP별 분당 10회로 제한한다. 기존 v1 토큰 URL은 계속 열린다.

## 5. 단계

1. `share-links.ts` — `createShareLink`:
   - 대상: `target_type`이 `recording`이면 `loadRecording(req, target_id, "recording:update")`, `document`이면 `document` 행을 읽어(없으면 `notFound(req, "문서")`) 그 `recording_id`로 같은 검사. 쿼리의 워크스페이스는 대상의 `workspace_id`로 정한다. 대상 타입과 id가 안 맞으면(`recording`인데 문서 id) 404.
   - 권한: 호출자가 `can_share !== 0`이고 `role !== "viewer"`이거나 `isAdminUser`여야 한다. 아니면 `apiError(req.c, 403, "forbidden", "외부 공유 링크 공개 권한이 제한된 계정입니다.")`.
   - `expires_at`이 있고 지금 이전이면 400 `"만료 시각은 지금보다 뒤여야 합니다."`.
   - 토큰: `randomBytes(18).toString("base64url")`(node:crypto). 행: `id = uuidv7()`, `token_hash = sha256Hex(token)`, `scope_json = JSON.stringify(scope)`, `password_hash = password ? hashPassword(password) : null`, `created_by = req.user!.id`.
   - 응답 201: `ok(req, { link: shareLinkDto(row), url: \`${config().baseUrl}/s/${token}\` }, { status: 201 })`. 토큰 원문은 로그·DB 어디에도 남기지 않는다(R17).
2. `updateShareLink`: 링크를 `share_link`에서 읽어 대상 녹음에 `recording:update` 검사(안 보이면 404). 회수된 링크는 404. 본문에 있는 필드만 바꾼다: `scope`, `expires_at`(`null`이면 해제), `password`(`null`이면 해제, 문자열이면 `hashPassword`). 응답 200 `shareLinkDto`.
3. `revokeShareLink`: 같은 검사 뒤 `UPDATE share_link SET revoked_at = ? WHERE id = ?`(이미 회수됐으면 그대로 204). **v1 링크 처리**: `recording.lecture_id`가 있고 `link.id === lectureShareLinkId(recording.lecture_id)`이면 `setLectureVisibility(lecture_id, false, false)`도 부른다(안 하면 `projectShareLink`가 다음 투영 때 회수를 되돌린다). 그 뒤 `announceLectures([lecture_id])`. 204.
4. `share-page.ts` — 구성:
   ```ts
   export function createShareRouter(): Hono   // GET/POST routes below
   export function renderSharePage(input: SharePageInput): string
   export class PasswordLimiter { constructor(limit: number, windowMs: number); allow(key: string, now?: number): boolean }
   ```
   - 링크 조회: `sha256Hex(decodeURIComponent(token))`로 `share_link`를 읽는다. **없거나 회수됐으면 `next()`**(옛 v1 처리기가 기존 404/403 문구를 그대로 낸다). 만료(`expires_at <= now`)면 410, 본문 `text/plain` `"만료된 공유 링크입니다."`.
   - `GET /s/:token`: 비밀번호가 없거나 유효한 쿠키가 있으면 페이지, 아니면 비밀번호 폼(`200`, `Cache-Control: no-store`).
   - `POST /s/:token`: `application/x-www-form-urlencoded`의 `password`. 제한기 키 = `${link.id}|${getClientIp(req) ?? "unknown"}`. `getClientIp`는 `index.ts`에서 import하지 말고(순환) `config().trustedProxyHops`와 `X-Forwarded-For`의 오른쪽에서 hops번째를 쓰는 같은 규칙으로 `share-page.ts`에 작은 함수를 둔다(없으면 `"unknown"`). 한도 초과면 429, `Retry-After: 60`, 폼에 `"시도가 너무 많습니다. 1분 뒤 다시 시도하세요."`. 틀리면 403 + 폼에 `"비밀번호가 올바르지 않습니다."`. 맞으면 303 `Location: /s/<token>`과 쿠키를 준다.
   - 쿠키: 이름 `lectern_share_` + `link.id` 앞 16자(영숫자), 값 `sha256Hex(link.password_hash + ":" + link.id)`, 속성 `Path=/s/<token>; HttpOnly; SameSite=Lax; Max-Age=86400`, `config().baseUrl`이 `http://`로 시작하지 않으면 `Secure`. 확인은 `timingSafeEqual`. 비밀번호를 바꾸면 해시가 달라져 쿠키가 무효가 된다.
   - `GET /s/:token/audio`: `scope.audio`가 참이고 비밀번호 통과일 때만. 녹음의 오디오 asset(`kind LIKE 'audio%'`, `part_index` 가장 작은 것 중 `audio` 우선)의 `assetPath`를 `serveFileWithRange(req, path, audioMimeForPath(path), { "Cache-Control": "private, no-store" })`. 아니면 404.
   - `GET /s/:token/markdown`: 비밀번호 통과일 때 문서 Markdown 첨부(`Content-Disposition` UTF-8 파일명).
   - 본문(문서) 선택: 대상이 문서면 그 문서, 녹음이면 `documentsOf(recording_id)[0]`. 현재 버전의 `body_json`이 있으면 `renderDocumentMarkdown(recording.title, JSON.parse(body_json))`, 없으면 `rendered_md`. 이것을 `renderMarkdownToHtml(...).html`로 바꾼다. 문서가 없으면 본문 자리에 `"공유된 문서가 없습니다."`.
   - 전사: `scope.transcript`가 참일 때만 `transcript_segment`를 `idx` 순으로 `<li>[MM:SS] 텍스트</li>`(모든 텍스트 `escapeHtml`)로 그린다. 거짓이면 전사 마크업을 **아예 출력하지 않는다**. 오디오도 같다(`<audio>`는 `scope.audio`가 참이고 asset이 있을 때만).
   - 마크업 규칙(AGENTS.md): 큰따옴표 속성, `escapeHtml`, 인라인 `<script>`·`<style>`·`style=`·`on*` 금지. 스크립트 `<script src="/share-assets/share.js?v=<hash>">`, 스타일 `<link rel="stylesheet" href="/share-assets/share.css?v=<hash>">`. `<title>`은 `${escapeHtml(title)} | Lectern`. 외부 오리진 금지(Pretendard CDN 쓰지 않음, 글꼴 스택만).
   - 골격: `<header class="share-topbar">`(브랜드 링크 `/app`, 버튼 `data-action="toggle-theme"` `테마 전환`, `<a>` `Markdown`, 버튼 `data-action="print"` `PDF 인쇄`), `<main class="container">` > `<article class="article-card">`(제목 `<h1>`, 오디오 바, `<div class="md-body">`본문, 전사 `<section aria-label="전사">`).
   - `GET /share-assets/share.js`, `share.css`: 문자열 상수에서 `Content-Type`(`text/javascript; charset=utf-8`, `text/css; charset=utf-8`), `Cache-Control: public, max-age=31536000, immutable`(URL에 해시가 붙어 있음). JS는 `data-action` 위임: 테마(`localStorage` `lectern_theme`는 try/catch로), 인쇄, `.ts-chip`의 `data-sec`로 오디오 이동. CSS는 `:root` 색 변수와 `@media (prefers-color-scheme: dark)`, `[data-theme="dark"]`, `.share-topbar`, `.container`, `.article-card`, `.md-body`(v1 `renderSharePageHtml` 스타일을 참고하되 `--elysium-*`는 쓰지 않는다). 폼 페이지에는 `<label for="password">비밀번호</label>`, `<input type="password" id="password" name="password" autocomplete="off" required>`, 버튼 `확인`을 쓴다.
   - 모든 응답에 `X-Content-Type-Options`·CSP는 `index.ts`의 `applySecurityHeaders`가 붙인다(`text/html`일 때). 페이지는 `Referrer-Policy`가 이미 `same-origin`. 추가로 `X-Robots-Tag: noindex`.
5. `http.ts`: `import { createShareRouter } from "./share-page.ts";` 후 `app.route("/", createShareRouter());`를 `app.all("*", …)` 위에 둔다. `GET /s/…`만 가로채고, 라우터에서 `next()`가 나면 아래 레거시로 간다.

## 10. 명세 작성자 메모

- `RateLimiter`와 `getClientIp`가 `index.ts`에 있어 `http.ts`가 쓰는 모듈에서 import하면 순환이다. 그래서 작은 제한기와 IP 함수를 `share-page.ts`에 따로 둔다(중복이지만 `index.ts`를 안 건드린다).
- v1에서 파생된 링크를 회수할 때 `setLectureVisibility`도 불러야 한다. 아니면 `projectShareLink`가 회수를 되돌린다(`packages/db/src/legacy.ts`).
- 계약은 "`/s/:token`을 서버가 그린다"이다. 회수·미존재 링크는 옛 처리기로 넘겨 기존 문구를 보존했다(계약에 없는 선택).
- 공유 페이지의 문서는 `documentsOf(...)[0]`(웹의 `detail.documents[0]`과 같은 기준)이다.
- `preflight.ts`는 소유 경로(`apps/server/`) 안이다. `PAGE_SCRIPTS`가 아니라 `/share-assets/*`를 쓰므로 직접 점검 표에 넣어야 한다.
