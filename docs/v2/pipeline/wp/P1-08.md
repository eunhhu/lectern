# P1-08 Markdown 렌더러

> 등급: `basic` · 게이트: `unit` · 의존: `P1-07` · 소유: `packages/harness/`
> (이 줄은 `pipeline.json`의 값과 같아야 한다.)

## 1. 목표

구조화 문서(`DocumentBody`)를 결정적인 Markdown 문자열로 바꾸는 `renderDocumentMarkdown`을 만든다. 같은 입력은 항상 같은 글자를 낸다. 이 글이 `document.rendered_md`와 `lectures.markdown`(v1 브리지)이 된다. 사용자가 보는 변화는 없다.

- 카탈로그: `CATALOG.md` P1-08 항목(섹션 `##`, 블록 heading `###`, 출처 `[MM:SS]`, 수식 `$…$`, callout 인용+굵은 꼬리표, gap `[쉬는 시간: 50:12~1:02:40]`).
- 코드: `packages/domain/src/blocks.ts` — `DocumentBody`, `DocumentBlock`의 각 필드(`ParagraphBlock`, `ListBlock`(`style`, `items[].text/sources`), `QuoteBlock`(`speaker`), `TermBlock`, `FormulaBlock`(`expression`, `explanation`), `CalloutBlock`(`tone`), `GapBlock`).

## 5. 단계

1. 시그니처.
   ```ts
   export interface RenderContext {
     /** Document title (the recording title); null/empty: no `# ` line. */
     title: string | null;
     /** idx → original-audio start, for the `[MM:SS]` source marker. */
     segments: readonly { idx: number; start_ms: number }[];
   }
   export function renderDocumentMarkdown(body: DocumentBody, ctx: RenderContext): string;
   export function escapeMarkdown(text: string): string;
   ```
2. `escapeMarkdown(text)`: (1) 줄바꿈 처리는 호출하는 쪽이 한다. (2) 문자 `\ * _ ` [ ] < > $` 앞에 `\`를 붙인다. (3) 그 다음 줄 시작(`m` 플래그)에서: `^(#{1,6})(\s)` → `\$1$2`, `^([-+])(\s)` → `\$1$2`, `^(\d+)\.(\s)` → `$1\.$2`. 그 밖의 문자(`~`, `|`, `!`, `&`)는 건드리지 않는다.
3. 한 줄 필드(heading, 목록 항목, 제목)는 먼저 `\s*\n\s*`를 공백 하나로 바꾸고 `trim` 한 뒤 이스케이프한다. 여러 줄 본문(paragraph/quote/callout `text`)은 줄을 그대로 두고 줄마다 이스케이프한다.
4. 출처 표지 `marker(sources)`: 첫 출처만 쓴다.
   - `kind: "transcript"`이고 `ctx.segments`에 `start_idx`가 있으면 ` [<시각>]`. 시각: 1시간 미만 `MM:SS`(분 0채움 `03:05`), 이상 `H:MM:SS`(`1:02:05`), 초 내림(P1-01 `compact.ts`의 시각 함수와 같은 규칙. 같은 함수가 export 되어 있으면 쓰고 없으면 이 파일에 같은 정의를 둔다).
   - `kind: "pdf_page"`이면 ` [p.<page>]`.
   - 출처가 없거나 idx를 못 찾으면 빈 문자열. 앞에 공백 하나를 포함한 문자열을 돌려준다.
5. 블록별 출력(한 블록 = 문자열 하나, 줄은 `\n`). `heading`이 null이 아니면 블록 맨 앞에 `### <heading>\n\n`을 붙인다.
   | type | 출력 |
   |---|---|
   | `paragraph` | `<text 이스케이프><marker(block.sources)>` |
   | `list` | 항목마다 한 줄. `bullet`: `- <항목><marker(item.sources)>`, `numbered`: `<n>. <항목><marker>`(n은 1부터). 블록 `sources`는 쓰지 않는다 |
   | `quote` | `text`의 줄마다 `> <줄>`. **마지막 줄** 끝에 `speaker`가 있으면 ` — <speaker>`, 그 뒤 `marker(block.sources)` |
   | `term` | `**<term 이스케이프>**: <definition 이스케이프><marker>` |
   | `formula` | `$<expression 원문 그대로>$`, `explanation`이 있으면 ` — <explanation 이스케이프>`, 그 뒤 marker |
   | `callout` | 꼬리표 `exam`→`시험`, `assignment`→`과제`, `important`→`중요`, `note`→`참고`. 첫 줄 `> **[<꼬리표>]** <첫 줄 본문>`, 나머지 줄은 `> <줄>`, 마지막 줄 끝에 marker |
   | `gap` | `formatGapMarker({ kind, start_ms, end_ms })` (marker 없음, `heading`이 있어도 무시) |
   | 그 밖(모르는 `type`) | 아무것도 내지 않는다(빈 줄도 만들지 않는다) |
6. 문서 조립.
   - `ctx.title`이 비어 있지 않으면 첫 조각이 `# <제목 한 줄 이스케이프>`.
   - 섹션마다: 렌더된 블록이 하나도 없으면 섹션 전체를 건너뛴다. 있으면 `## <섹션 title 한 줄 이스케이프>` 다음에 블록들.
   - 조각(제목, 섹션 머리, 각 블록)은 빈 줄 하나(`\n\n`)로 잇는다. 문자열은 `\n` 하나로 끝낸다. 렌더된 조각이 하나도 없으면 `""`.
   - 줄 끝 공백 없음, 탭 없음.
7. `src/index.ts`에 export를 더한다.

## 6. 테스트

파일: `packages/harness/test/render.test.ts`. 공통 `ctx`: `title: "암호 운영 모드"`, `segments: [{idx:1,start_ms:63000},{idx:2,start_ms:3725000},{idx:3,start_ms:3800000}]`. `src(i) = [{kind:"transcript",start_idx:i,end_idx:i}]`. 블록 `id`는 `b1`… 아무 값.

**기준 문서(lecture)** — 섹션 `summary`(제목 `핵심 요약`): ① paragraph `heading null`, text `ECB는 같은 평문이 같은 암호문이 된다.`, sources `src(1)` ② list bullet, 항목 `{text:"CBC는 IV가 필요하다", sources: src(2)}`, `{text:"CTR은 병렬 처리가 된다", sources: []}`. 섹션 `topics`(제목 `주제별 상세`): ③ term heading `블록 암호`, term `ECB`, definition `각 블록을 독립적으로 암호화`, sources `src(1)` ④ gap `kind:"break"`, `start_ms:3012000`, `end_ms:3760000`, sources `[]`, heading null ⑤ formula expression `C_i = E_K(P_i)`, explanation `ECB 암호화`, sources `src(3)` ⑥ callout tone `exam`, text `ECB의 약점이 시험에 나온다`, sources `src(1)` ⑦ quote text `중요한 건 IV입니다`, speaker `S1`, sources `src(2)` ⑧ list numbered 항목 `첫째`, `둘째`(sources 없음) ⑨ paragraph text `# 제목 아님 *강조* a_b`, sources `[]`.

| 테스트 이름 | 준비 | 기대 |
|---|---|---|
| exact output of the reference document | 위 문서 | 아래 코드 블록의 문자열과 **완전히 같다** |
| same input gives the same output | 두 번 호출 | `===` |
| escapes user text | ⑨ 단독 | `\# 제목 아님 \*강조\* a\_b\n`을 포함(제목 없는 ctx로 `\n`까지 비교) |
| escapeMarkdown | `"a[1]<b>$"`, `"- 항목"`, `"3. 항목"`, `"~|!&"` | `a\[1\]\<b\>\$`, `\- 항목`, `3\. 항목`, `~|!&` |
| formula expression is not escaped | ⑤ | `$C_i = E_K(P_i)$`가 그대로 들어 있음 |
| marker uses the first source only | sources `[src(1)[0], src(2)[0]]` | ` [01:03]` 하나만, `1:02:05` 없음 |
| unknown segment idx gives no marker | sources `src(99)` | marker 없음, 줄 끝 공백 없음 |
| pdf page marker | sources `[{kind:"pdf_page",asset_id:"a1",page:3}]` | ` [p.3]` |
| hour clock | start_ms `3725000` → `1:02:05`; `63000` → `01:03` | 위 출력과 같음 |
| unknown block type is skipped | 섹션에 `{id:"x",type:"video",sources:[]}`(타입 단언)과 ① | 출력에 `video` 없음, 빈 줄이 두 번 연속 `\n\n\n`이 되지 않음 |
| empty section is skipped | 섹션 blocks `[]` | 그 섹션의 `## ` 줄이 없음 |
| empty body | `{sections: []}`, `title: null` | `""` |
| title null or blank | `title: null`, `"  "` | `# `로 시작하지 않음 |
| single-line fields flatten newlines | heading `"가\n나"`, list 항목 `"다\n라"` | `### 가 나`, `- 다 라` |
| multi-line callout and quote | callout text `"가\n나"`, quote text `"다\n라"` + speaker | `> **[시험]** 가\n> 나`; `> 다\n> 라 — S1` |
| numbered list counts from 1 | 항목 3개 | `1. `, `2. `, `3. ` |
| snapshot per template | `TEMPLATE_IDS` 5개마다: `loadTemplate(id).def.sections`로 body 생성(섹션마다 paragraph 하나, text `<섹션 title> 내용`, sources `src(1)`), `render` 결과 `toMatchSnapshot()` | 스냅샷 5개; 각각 모든 섹션 `## <title>` 줄을 포함(`def.sections` 순서) |
| output ends with one newline | 위 문서 | `endsWith("\n")`이고 `endsWith("\n\n")`가 아님 |

기준 문서의 기대 출력(끝에 개행 하나):
```
# 암호 운영 모드

## 핵심 요약

ECB는 같은 평문이 같은 암호문이 된다. [01:03]

- CBC는 IV가 필요하다 [1:02:05]
- CTR은 병렬 처리가 된다

## 주제별 상세

### 블록 암호

**ECB**: 각 블록을 독립적으로 암호화 [01:03]

[쉬는 시간: 50:12~1:02:40]

$C_i = E_K(P_i)$ — ECB 암호화 [1:03:20]

> **[시험]** ECB의 약점이 시험에 나온다 [01:03]

> 중요한 건 IV입니다 — S1 [1:02:05]

1. 첫째
2. 둘째

\# 제목 아님 \*강조\* a\_b
```

## 10. 명세 작성자 메모

- 계약은 `renderDocumentMarkdown(body, ctx)`의 `ctx`를 정하지 않았다. 출처 시각을 구하려면 idx→시각 대응이, 제목 줄에는 제목이 필요해서 `{ title, segments }`로 정했다(P1-09가 채운다).
- 출처 표지를 블록 끝 한 개로 했고 list는 항목별로 달았다. 카탈로그의 "블록 끝에 첫 출처 시각"을 list에 맞게 확장한 해석이다. pdf 쪽 표지 `[p.N]`은 카탈로그에 없는 추가다.
- v1 웹 렌더러(`packages/core/src/markdown.ts`)는 `[쉬는 시간 생략: …]` 문구를 뱃지로 바꾸는데, 계약의 gap 표기(`@lectern/media` `formatGapMarker`)는 `[쉬는 시간: …]`이라 v1 화면에서는 뱃지가 아닌 글자로 보일 수 있다. 계약대로 쓴다. 또 v1 렌더러가 백슬래시 이스케이프를 처리하는지 확인하지 못했다(`\*`가 그대로 보일 수 있음). 이스케이프 문자를 최소로 줄인 이유다.
