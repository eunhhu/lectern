# P5-01 세션 메타와 기기 목록

> 등급: `basic` · 게이트: `full` · 의존: `P5-C` · 소유: `apps/server/`
> (이 줄은 `pipeline.json`의 값과 같아야 한다.)

## 1. 목표

설정의 "로그인된 기기" 목록이 기기 이름("Mac의 Chrome")과 마지막 사용 시각을 보여 준다. 지금은 둘 다 비어 있다. 로그인할 때 기기 정보를 기록하고, 요청이 올 때 마지막 사용 시각을 (5분에 한 번만) 갱신한다.

## 2. 먼저 읽을 것

- 계약: `CONTRACTS.md` D-P5-2, §5 DB(`auth_session_meta`), D-0-4(v1 `sessions` 테이블은 고치지 않는다)
- 레시피: `RECIPES.md` R3, R12, R13
- 코드: `apps/server/src/api/v2/me.ts` — `listDevices`, `revokeDevice`, `deviceIdOf`(세션의 공개 id = `ses_` + 토큰 sha256 앞 32자)
- 코드: `apps/server/src/db.ts` — `createSession`, `deleteSession`; `apps/server/src/auth.ts` — `resolveActiveUser`, `extractAuthToken`
- 코드: `apps/server/src/index.ts` — `createSession(`을 부르는 곳(로그인, 가입), 로그아웃 처리

## 5. 단계

1. `session-meta.ts`
   ```ts
   export const sessionIdOf = (token: string) => `ses_${sha256Hex(token).slice(0, 32)}`;   // moved from me.ts; the token itself is never stored
   export function deviceNameFromUserAgent(ua: string | null): string | null
   export function recordSessionMeta(token: string, userId: string, req: Request): void
   export function touchSession(token: string, now?: number): void        // writes at most once per 5 minutes per session
   export function deleteSessionMeta(token: string): void
   export function deleteSessionMetaOfUser(userId: string): void
   export function sessionMetaOf(userId: string): Map<string, { deviceName: string | null; userAgent: string | null; lastSeenAt: number }>
   ```
   - `deviceNameFromUserAgent`: `<기기>의 <브라우저>`. 판별은 아래 순서로 **처음 맞는 것**을 쓴다.
     - 기기: `iPhone` → `iPhone`, `iPad` → `iPad`, `Android` → `Android`, `Macintosh` 또는 `Mac OS X` → `Mac`, `Windows` → `Windows`, `Linux` → `Linux`, `CrOS` → `Chromebook`. 없으면 `null`.
     - 브라우저: `Edg/` → `Edge`, `OPR/` → `Opera`, `Whale/` → `Whale`, `SamsungBrowser/` → `삼성 인터넷`, `Firefox/` 또는 `FxiOS/` → `Firefox`, `Chrome/` 또는 `CriOS/` → `Chrome`, `Safari/` → `Safari`. 없으면 `null`.
     - 둘 다 있으면 `Mac의 Chrome`, 기기만 있으면 `Mac`, 브라우저만 있으면 `Chrome`, 둘 다 없거나 `ua`가 비면 `null`.
   - `recordSessionMeta`: `session_id = sessionIdOf(token)`, `client_kind = 'web'`, `user_agent`는 헤더 값 앞 512자, `device_name`은 위 함수, `created_at = last_seen_at = now`. `INSERT OR REPLACE`.
   - `touchSession`: 모듈 안의 `Map<sessionId, lastWriteMs>`를 보고 5분이 안 지났으면 아무것도 하지 않는다. 지났으면 `UPDATE auth_session_meta SET last_seen_at = ? WHERE session_id = ?`(행이 없으면 아무 일도 없다. 옛 세션에 행을 만들지 않는다). 맵이 10,000개를 넘으면 비운다.
2. `index.ts`: `createSession(`을 부르는 모든 곳 바로 다음 줄에 `recordSessionMeta(token, user.id, req)`를 넣는다. `deleteSession(token)`을 부르는 곳 다음에 `deleteSessionMeta(token)`. 사용자의 세션을 모두 지우는 곳(비밀번호 변경·재설정)이 있으면 `deleteSessionMetaOfUser(userId)`.
3. `auth.ts`: `resolveActiveUser(token)`이 **세션 토큰으로** 사용자를 찾았을 때만 `touchSession(token)`을 부른다(API 토큰으로 찾았을 때는 부르지 않는다). `touchSession`이 던져도 인증은 실패하지 않게 `try/catch`.
4. `me.ts` `listDevices`: `sessionMetaOf(user.id)`를 읽어 `device_name`, `user_agent`, `last_seen_at`을 채운다. 메타가 없는 옛 세션은 지금처럼 `device_name: null`, `user_agent: null`, `last_seen_at = 로그인 시각`이다. `revokeDevice`는 세션을 지운 뒤 `deleteSessionMeta(session.token)`.

## 6. 테스트

`session-meta.test.ts`

| 테스트 이름 | 준비 | 기대 |
|---|---|---|
| "device names" | 아래 표의 UA | 아래 표의 이름 |
| "login records the device" | `User-Agent`를 실어 `/api/auth/login` → `listDevices` | `device_name === "Mac의 Chrome"`, `user_agent`가 보낸 값, `current: true` |
| "sessions from before have null names" | `createSession`만 직접 부름 | `device_name === null`, `last_seen_at === created_at` |
| "last_seen_at moves at most every 5 minutes" | 행의 `last_seen_at`을 `T`로 고친 뒤 `touchSession(t, T + 1000)`(이 프로세스의 첫 호출), `touchSession(t, T + 61_000)`, `touchSession(t, T + 302_000)` | 첫 호출 뒤 `T + 1000`, 둘째 뒤 그대로 `T + 1000`, 셋째 뒤 `T + 302_000` |
| "logout removes the row" | 로그아웃 | `auth_session_meta`에 그 `session_id` 없음 |
