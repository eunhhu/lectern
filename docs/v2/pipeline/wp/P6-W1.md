# P6-W1 Windows: v2 파트 업로드

> 등급: `careful` · 게이트: `windows` · 의존: `P1-12` · 소유: `apps/windows/`
> (이 줄은 `pipeline.json`의 값과 같아야 한다.)

**사용자가 필요하다.** 이 앱은 로컬(macOS)에서 컴파일할 수 없다. 컴파일은 PR의 `windows-native` CI 작업이, 실제 동작(녹음 → 업로드)은 Windows 기기를 가진 사용자가 확인한다. 워커는 코드를 쓰고 7절의 정적 확인까지만 한다.

## 1. 목표

Windows 트레이 앱이 녹음을 v2 업로드 API로 올린다. 지금은 WAV 파일 전체를 메모리에 읽어(`File.ReadAllBytesAsync`) 한 요청으로 보낸다. 이 작업 뒤에는 8 MiB 파트로 나눠 보내고, 재시도할 때 서버가 이미 받은 파트는 건너뛴다. 그리고 모든 요청에 `X-Client: windows-native-tray`를 보낸다(P6-03의 v1 사용 집계가 이 앱을 구분한다). 옛 방식은 환경 변수 `LECTERN_UPLOAD_API=v1` 뒤에 남는다.

## 2. 먼저 읽을 것

- 계약: `CONTRACTS.md` D-P6-5, D-P6-6
- domain(읽기만): `packages/domain/src/api/uploads.ts`, `common.ts`(`ApiError` = `{ "error": { "code", "message" } }`, 헤더 `Idempotency-Key`), `resources.ts`(`Me.personal_workspace_id`, `Folder`, `CreateFolderRequest`)
- 서버(읽기만): `apps/server/src/api/v2/uploads.ts` — 같은 `Idempotency-Key`·같은 본문의 `createUpload`는 기존 세션을 돌려준다. 파트 길이는 정확해야 한다. 끝난 세션의 `completeUpload`는 저장된 결과를 다시 준다
- 코드: `apps/windows/Program.cs` — `UploadAndRefreshAsync`, `RefreshLecturesAsync`, `LoadLectureDetailAsync`, 필드 `_serverBase`, `_tokenBox`, `_statusLabel`; `apps/windows/LecternTray.csproj`(`net8.0-windows`, `ImplicitUsings`, `Nullable`)
- 같은 일을 하는 Android 명세: `wp/P6-D1.md`(규칙이 같다. 이름만 C#식이다)

## 5. 단계

1. `apps/windows/UploadV2.cs`를 **아래 내용 그대로** 만든다(컴파일을 로컬에서 확인할 수 없으므로 고쳐 쓰지 않는다).
   ```csharp
   using System.Globalization;
   using System.Net.Http.Headers;
   using System.Security.Cryptography;
   using System.Text;
   using System.Text.Json;

   namespace LecternTray;

   /// <summary>A non-2xx answer from the v2 API. ApiCode is `error.code` ("" when the body was not an API error).</summary>
   internal sealed class UploadV2Exception : Exception
   {
       public int Status { get; }
       public string ApiCode { get; }

       public UploadV2Exception(int status, string apiCode, string message) : base(message)
       {
           Status = status;
           ApiCode = apiCode;
       }

       /// <summary>Timeouts, rate limits and server errors are worth another attempt; other 4xx answers are final.</summary>
       public bool IsRetryable => Status == 408 || Status == 429 || Status >= 500;
   }

   internal sealed record UploadSessionInfo(string Id, string Status, long PartSize, int FirstPart, int PartCount, HashSet<int> ReceivedParts);

   /// <summary>
   /// Resumable upload against /api/v2/uploads: create a session, PUT the parts the server does not have yet, complete.
   /// Stateless: calling UploadAsync again with the same file resumes, because createUpload returns the existing
   /// session for the same Idempotency-Key and body.
   /// </summary>
   internal static class UploadV2
   {
       public const string ClientName = "windows-native-tray";
       private const string ApiBase = "/api/v2";
       private const int MaxGenerations = 3;

       public static HttpClient NewClient(string token, TimeSpan timeout)
       {
           var client = new HttpClient { Timeout = timeout };
           if (!string.IsNullOrWhiteSpace(token)) client.DefaultRequestHeaders.Add("X-Lectern-Token", token.Trim());
           client.DefaultRequestHeaders.Add("X-Client", ClientName);
           return client;
       }

       /// <summary>ASCII-only key derived from the file name (file names carry the course, which may be Korean).</summary>
       public static string IdempotencyKey(string fileName, int generation)
       {
           var hash = Convert.ToHexString(SHA256.HashData(Encoding.UTF8.GetBytes(fileName))).ToLowerInvariant().Substring(0, 32);
           return generation == 0 ? $"win_{hash}" : $"win_{hash}-g{generation}";
       }

       public static (long Offset, long Length) PartRange(long fileBytes, long partSize, int firstPart, int part)
       {
           var offset = (part - firstPart) * partSize;
           return (offset, Math.Min(partSize, fileBytes - offset));
       }

       public static List<int> MissingParts(UploadSessionInfo session)
       {
           var missing = new List<int>();
           for (var part = session.FirstPart; part < session.FirstPart + session.PartCount; part++)
           {
               if (!session.ReceivedParts.Contains(part)) missing.Add(part);
           }
           return missing;
       }

       /// <summary>Must be byte-identical for the same input: the server compares the body of a repeated Idempotency-Key.</summary>
       public static string CreateBody(string workspaceId, string fileName, long bytes, string? folderId)
       {
           var sb = new StringBuilder();
           sb.Append("{\"workspace_id\":").Append(JsonSerializer.Serialize(workspaceId));
           if (folderId != null) sb.Append(",\"recording\":{\"folder_id\":").Append(JsonSerializer.Serialize(folderId)).Append('}');
           sb.Append(",\"files\":[{\"kind\":\"audio\",\"filename\":").Append(JsonSerializer.Serialize(fileName));
           sb.Append(",\"mime\":\"audio/wav\",\"bytes\":").Append(bytes.ToString(CultureInfo.InvariantCulture)).Append("}]}");
           return sb.ToString();
       }

       /// <summary>Uploads the file and returns the id of the recording it became.</summary>
       public static async Task<string> UploadAsync(HttpClient client, string serverBase, string filePath, string course, Action<int, int>? onProgress = null)
       {
           var fileName = Path.GetFileName(filePath);
           var fileBytes = new FileInfo(filePath).Length;
           var workspaceId = await PersonalWorkspaceIdAsync(client, serverBase);
           var folderId = await FolderIdForCourseAsync(client, serverBase, workspaceId, course);
           var body = CreateBody(workspaceId, fileName, fileBytes, folderId);

           UploadSessionInfo? session = null;
           var key = "";
           for (var generation = 0; generation < MaxGenerations && session == null; generation++)
           {
               key = IdempotencyKey(fileName, generation);
               try
               {
                   var created = await CreateUploadAsync(client, serverBase, key, body);
                   // An expired or aborted session cannot take parts: move on to the next generation's key.
                   if (created.Status == "open" || created.Status == "completed") session = created;
               }
               catch (UploadV2Exception ex) when (ex.Status == 409 && ex.ApiCode == "idempotency_conflict")
               {
                   // The body changed since the first attempt (the folder exists now): next generation.
               }
           }
           if (session == null) throw new UploadV2Exception(409, "conflict", "업로드 세션을 만들지 못했습니다.");

           if (session.Status == "open") await PutMissingPartsAsync(client, serverBase, session, filePath, fileBytes, onProgress);
           try
           {
               return await CompleteAsync(client, serverBase, session.Id, key);
           }
           catch (UploadV2Exception ex) when (ex.Status == 409 && ex.ApiCode == "upload_incomplete")
           {
               var again = await GetUploadAsync(client, serverBase, session.Id);
               await PutMissingPartsAsync(client, serverBase, again, filePath, fileBytes, onProgress);
               return await CompleteAsync(client, serverBase, session.Id, key);
           }
       }

       private static async Task<string> PersonalWorkspaceIdAsync(HttpClient client, string serverBase)
       {
           using var doc = await SendAsync(client, HttpMethod.Get, $"{serverBase}{ApiBase}/me", null, null);
           return doc.RootElement.GetProperty("personal_workspace_id").GetString() ?? "";
       }

       /// <summary>The v1 "course" is a top-level folder name in v2. Finds it, or creates it; null for a blank course.</summary>
       private static async Task<string?> FolderIdForCourseAsync(HttpClient client, string serverBase, string workspaceId, string course)
       {
           var name = course.Trim();
           if (name.Length == 0) return null;
           var found = await FindFolderAsync(client, serverBase, workspaceId, name);
           if (found != null) return found;
           try
           {
               var body = "{\"workspace_id\":" + JsonSerializer.Serialize(workspaceId) + ",\"name\":" + JsonSerializer.Serialize(name) + "}";
               using var doc = await SendAsync(client, HttpMethod.Post, $"{serverBase}{ApiBase}/folders", JsonContent(body), null);
               return doc.RootElement.GetProperty("id").GetString();
           }
           catch (UploadV2Exception ex) when (ex.Status == 409)
           {
               // Created concurrently: it is in the list now.
               return await FindFolderAsync(client, serverBase, workspaceId, name);
           }
       }

       private static async Task<string?> FindFolderAsync(HttpClient client, string serverBase, string workspaceId, string name)
       {
           string? cursor = null;
           for (var page = 0; page < 5; page++)
           {
               var url = $"{serverBase}{ApiBase}/folders?workspace_id={Uri.EscapeDataString(workspaceId)}&limit=200";
               if (cursor != null) url += $"&cursor={Uri.EscapeDataString(cursor)}";
               using var doc = await SendAsync(client, HttpMethod.Get, url, null, null);
               foreach (var folder in doc.RootElement.GetProperty("items").EnumerateArray())
               {
                   var isTopLevel = folder.GetProperty("parent_id").ValueKind == JsonValueKind.Null;
                   var folderName = (folder.GetProperty("name").GetString() ?? "").Trim();
                   if (isTopLevel && string.Equals(folderName, name, StringComparison.OrdinalIgnoreCase)) return folder.GetProperty("id").GetString();
               }
               var next = doc.RootElement.GetProperty("next_cursor");
               if (next.ValueKind != JsonValueKind.String) return null;
               cursor = next.GetString();
           }
           return null;
       }

       private static async Task<UploadSessionInfo> CreateUploadAsync(HttpClient client, string serverBase, string key, string body)
       {
           using var doc = await SendAsync(client, HttpMethod.Post, $"{serverBase}{ApiBase}/uploads", JsonContent(body), key);
           return ParseSession(doc.RootElement);
       }

       private static async Task<UploadSessionInfo> GetUploadAsync(HttpClient client, string serverBase, string uploadId)
       {
           using var doc = await SendAsync(client, HttpMethod.Get, $"{serverBase}{ApiBase}/uploads/{Uri.EscapeDataString(uploadId)}", null, null);
           return ParseSession(doc.RootElement);
       }

       private static async Task PutMissingPartsAsync(HttpClient client, string serverBase, UploadSessionInfo session, string filePath, long fileBytes, Action<int, int>? onProgress)
       {
           var done = session.ReceivedParts.Count;
           await using var stream = new FileStream(filePath, FileMode.Open, FileAccess.Read, FileShare.Read);
           foreach (var part in MissingParts(session))
           {
               var (offset, length) = PartRange(fileBytes, session.PartSize, session.FirstPart, part);
               // One part (8 MiB) in memory at a time, never the whole recording.
               var buffer = new byte[length];
               stream.Seek(offset, SeekOrigin.Begin);
               await stream.ReadExactlyAsync(buffer, 0, buffer.Length);
               var content = new ByteArrayContent(buffer);
               content.Headers.ContentType = new MediaTypeHeaderValue("application/octet-stream");
               var url = $"{serverBase}{ApiBase}/uploads/{Uri.EscapeDataString(session.Id)}/parts/{part.ToString(CultureInfo.InvariantCulture)}";
               using var doc = await SendAsync(client, HttpMethod.Put, url, content, null);
               done++;
               onProgress?.Invoke(done, session.PartCount);
           }
       }

       private static async Task<string> CompleteAsync(HttpClient client, string serverBase, string uploadId, string key)
       {
           using var doc = await SendAsync(client, HttpMethod.Post, $"{serverBase}{ApiBase}/uploads/{Uri.EscapeDataString(uploadId)}/complete", null, key);
           return doc.RootElement.GetProperty("recording").GetProperty("id").GetString() ?? "";
       }

       private static UploadSessionInfo ParseSession(JsonElement root)
       {
           var file = root.GetProperty("files")[0];
           var received = new HashSet<int>();
           foreach (var part in root.GetProperty("received_parts").EnumerateArray()) received.Add(part.GetInt32());
           return new UploadSessionInfo(
               root.GetProperty("id").GetString() ?? "",
               root.GetProperty("status").GetString() ?? "",
               root.GetProperty("part_size").GetInt64(),
               file.GetProperty("first_part").GetInt32(),
               file.GetProperty("part_count").GetInt32(),
               received);
       }

       private static StringContent JsonContent(string body) => new StringContent(body, Encoding.UTF8, "application/json");

       private static async Task<JsonDocument> SendAsync(HttpClient client, HttpMethod method, string url, HttpContent? content, string? idempotencyKey)
       {
           using var request = new HttpRequestMessage(method, url) { Content = content };
           if (idempotencyKey != null) request.Headers.Add("Idempotency-Key", idempotencyKey);
           using var response = await client.SendAsync(request);
           var text = await response.Content.ReadAsStringAsync();
           if (!response.IsSuccessStatusCode)
           {
               var status = (int)response.StatusCode;
               var code = "";
               var message = $"HTTP {status}";
               try
               {
                   using var err = JsonDocument.Parse(text);
                   if (err.RootElement.ValueKind == JsonValueKind.Object && err.RootElement.TryGetProperty("error", out var e) && e.ValueKind == JsonValueKind.Object)
                   {
                       if (e.TryGetProperty("code", out var c)) code = c.GetString() ?? "";
                       if (e.TryGetProperty("message", out var m)) message = m.GetString() ?? message;
                   }
               }
               catch (JsonException)
               {
                   // Not JSON (a proxy error page): keep "HTTP <status>".
               }
               throw new UploadV2Exception(status, code, message);
           }
           return JsonDocument.Parse(string.IsNullOrWhiteSpace(text) ? "{}" : text);
       }
   }
   ```

   ```csharp
   private async Task UploadAndRefreshAsync(string filePath, string course)
   {
       if (!File.Exists(filePath)) return;
       for (int attempt = 1; attempt <= 3; attempt++)
       {
           try
           {
               if (attempt > 1)
               {
                   _statusLabel.Text = $"업로드 자동 재시도 중 ({attempt}/3)...";
                   await Task.Delay(attempt * 2000);
               }
               using var client = UploadV2.NewClient(_tokenBox.Text, TimeSpan.FromMinutes(5));
               string? newId;
               if (_useV1Upload)
               {
                   newId = await UploadV1Async(client, filePath, course);
               }
               else
               {
                   newId = await UploadV2.UploadAsync(client, _serverBase, filePath, course, (done, total) =>
                   {
                       _statusLabel.Text = $"업로드 중 ({done}/{total})...";
                   });
               }
               await RefreshLecturesAsync(newId);
               ShowMainWindow();
               return;
           }
           catch (UploadV2Exception ex) when (!ex.IsRetryable)
           {
               // A final answer (bad token, quota, unsupported file): retrying cannot help.
               _statusLabel.Text = $"업로드 거부 ({ex.Status}) (원본 보존됨: Documents\\LecternRecordings): {ex.Message}";
               return;
           }
           catch (Exception ex)
           {
               _statusLabel.Text = $"업로드 지연 (원본 보존됨: Documents\\LecternRecordings): {ex.Message}";
           }
       }
   }

   private async Task<string?> UploadV1Async(HttpClient client, string filePath, string course)
   {
       var idempotencyKey = $"win_{Path.GetFileName(filePath)}";
       using var form = new MultipartFormDataContent();
       form.Add(new StringContent(course), "course");
       form.Add(new StringContent(UploadV2.ClientName), "source");
       form.Add(new StringContent(idempotencyKey), "idempotency_key");

       var bytes = await File.ReadAllBytesAsync(filePath);
       var fileContent = new ByteArrayContent(bytes);
       fileContent.Headers.ContentType = new MediaTypeHeaderValue("audio/wav");
       form.Add(fileContent, "audio", Path.GetFileName(filePath));

       using var request = new HttpRequestMessage(HttpMethod.Post, $"{_serverBase}/api/ingest/shortcut?wait=false") { Content = form };
       request.Headers.TryAddWithoutValidation("X-Idempotency-Key", idempotencyKey);
       using var res = await client.SendAsync(request);
       res.EnsureSuccessStatusCode();
       var body = await res.Content.ReadAsStringAsync();
       using var doc = JsonDocument.Parse(body);
       return doc.RootElement.TryGetProperty("id", out var idEl) ? idEl.GetString() : null;
   }
   ```
   - 진행 콜백은 UI 스레드에서 불린다(`await` 뒤의 이어짐이 WinForms 동기화 컨텍스트로 돌아온다. `ConfigureAwait(false)`를 넣지 않는다).
   - v2가 돌려주는 녹음 id는 v1의 강의 id와 같은 값이다. `RefreshLecturesAsync(newId)`가 그대로 그 항목을 고른다.
5. `apps/windows/README.md`: 환경 변수 표(`LECTERN_URL` — 서버 주소, 기본은 코드의 값. `LECTERN_UPLOAD_API` — `v1`이면 옛 업로드), 빌드 명령(CI의 `dotnet publish` 줄), 수동 확인 절차(8줄 이내): ① 토큰 입력 ② 짧은 녹음 → 목록에 생긴다 ③ 20분 이상 녹음(16 kHz 모노 WAV는 약 1.9 MB/분이라 8 MiB를 넘는다) → 상태 줄에 `업로드 중 (1/N)`이 보인다 ④ 업로드 중 네트워크를 껐다 켠다 → 자동 재시도로 끝난다 ⑤ `LECTERN_UPLOAD_API=v1`로 실행 → 옛 경로로 올라간다.

## 10. 명세 작성자 메모

- 이 명세의 C# 코드는 컴파일해 보지 못했다(이 기계에 `dotnet`이 없다). .NET 8의 API(`Stream.ReadExactlyAsync`, `SHA256.HashData`, `Convert.ToHexString`)만 썼다. CI에서 컴파일 오류가 나면 그 오류만 고친다(동작을 바꾸지 않는다).
- 멱등 키를 파일 이름의 해시로 바꿨다. 파일 이름에 과목명(한글)이 들어가는데 HTTP 헤더에는 ASCII만 안전하다. v1 경로의 키(`win_<파일 이름>`)는 그대로 두되 `TryAddWithoutValidation`으로 넣는다.
- 세대 번호(`-g1`, `-g2`)를 앱이 기억하지 않는다. 매번 0부터 시도하고, 죽은 세션이면 다음 번호로 넘어간다(요청이 한두 번 더 든다).
- `X-Client`를 `/api/lectures` 요청에도 보내게 한 것은 P6-03의 집계 때문이다. 이 값이 없으면 Windows 앱은 `no-ua`로 묶인다.
- `/api/lectures`는 P6-03의 차단 대상이다. `LECTERN_V1_BLOCK`을 켜기 전에 이 앱의 읽기 경로도 옮겨야 한다. 이 파이프라인에 그 작업은 없다(STATUS에 적었다).
