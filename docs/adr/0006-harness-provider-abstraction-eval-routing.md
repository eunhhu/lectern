# ADR-0006: AI 하네스의 공급자 추상화와 평가 기반 라우팅

- 상태: 채택(메커니즘). 단계별 공급자·모델 선택(D1 전사, D3 텍스트 단계)은 **P1 평가 결과로 결정**하며 이 ADR에서 정하지 않는다.
- 날짜: 2026-10-19
- 관련: [ROADMAP.md D1·D3·D11](../v2/ROADMAP.md#결정-필요-사항), [AI_HARNESS.md §5](../v2/AI_HARNESS.md#5-공급자-추상화와-라우팅), [§8](../v2/AI_HARNESS.md#8-평가eval와-품질-게이트)

## 맥락 (Context)

현재 AI 경로는 `packages/core/src/gemini.ts`의 `distillLectureAudio()` 하나다. 오디오를 Gemini File API에 올리고 **한 번의 호출로 Markdown을 받는다.** 모델 ID는 최근 `gemini-3.8-flash`로 고정했고(`-latest` 별칭은 Google이 예고 없이 다른 모델로 돌린다), 요청이 고를 수 있는 모델은 서버 허용 목록으로 제한한다.

v2 하네스는 전사 → 구조화 → 추출 → 검증의 여러 단계로 나뉜다. 단계마다 맞는 공급자가 다를 수 있다.

- 전사(D1): Gemini 오디오 입력, 전용 STT(Soniox, ElevenLabs Scribe, RTZR 등). 한국어 정확도의 공개 수치는 업체 발표뿐이라 우리 녹음으로 직접 재야 한다.
- 텍스트 단계(D3): Gemini Flash 계열, Claude(Sonnet/Haiku/Opus). Claude는 오디오 입력이 없어 전사를 맡지 못한다.
- 단가는 자주 바뀐다. Gemini Flash 단가는 2027-01-01에 2배가 되는 것으로 공지돼 있다(D11 재평가 트리거).

공급자를 코드 곳곳에 박아 넣으면 공급자를 바꿀 때마다 파이프라인을 고쳐야 하고, 바꾸는 근거도 감에 의존하게 된다.

## 결정 (Decision)

1. **공급자 인터페이스를 둔다.** `TranscriptionProvider`(청크 오디오 → 세그먼트)와 `LlmProvider`(zod 스키마로 구조화 출력 강제)다. 정의는 [AI_HARNESS.md §5](../v2/AI_HARNESS.md#5-공급자-추상화와-라우팅)를 따른다. 단계 코드는 인터페이스만 알고, 공급자 SDK나 HTTP 형식을 모른다.
2. **라우팅은 코드가 아니라 설정 파일**(`harness.routing.json`)에 둔다. 단계마다 `primary`, `fallback`, 모델 ID, 동시성 상한을 정한다. 기본값은 현행 Gemini 경로다.
3. **모델 ID는 버전을 고정한다.** `-latest` 같은 별칭은 쓰지 않는다. 응답의 실제 모델 버전을 `ai_call`에 기록한다.
4. **라우팅·모델·프롬프트·템플릿 변경은 평가를 거친다.**
   - 평가 세트 v0(익명화·동의받은 녹음 10건 이상)와 `bun run harness eval` 리포트로 비교한다.
   - 변경 PR은 평가 리포트를 첨부하고, 핵심 지표가 정한 폭 이상 나빠지면 머지하지 않는다.
   - LLM 판정은 평가에서만 쓰고 운영 경로에는 넣지 않는다.
5. **공급자 등록 조건**: 입력을 모델 학습에 쓰지 않는 유료 계층·조건에서만 쓴다. Gemini는 유료 서비스(Paid Services) 키만 운영에 쓴다. 새 공급자를 추가할 때 이 조건과 데이터 보관 조건을 확인해 어댑터 문서에 남기고, [개인정보처리방침](../../apps/server/static/legal/privacy.html)의 처리 위탁 목록을 갱신한다.
6. 모든 호출의 사용량과 금액을 `ai_call` 원장에 남기고, 녹음과 워크스페이스 단위로 합산한다.

이 ADR이 정하지 않는 것
- D1(전사 공급자)과 D3(텍스트 단계 모델)의 선택. P1 평가가 끝나면 각각 새 ADR로 남긴다.
- D11(1시간당 비용 목표)의 최종 수치. P1 첫 측정 후 확정한다.

## 결과 (Consequences)

- 좋아지는 것
  - 공급자 교체와 장애 시 대체가 설정 변경으로 끝난다.
  - 모델·프롬프트 변경의 품질과 비용 영향을 숫자로 비교한다.
  - 단가 변경(예: 2027-01 Flash 인상)에 맞춰 같은 평가를 다시 돌려 라우팅을 정할 수 있다.
- 감수하는 것
  - 인터페이스가 공급자 고유 기능(컨텍스트 캐시, PDF 페이지 인용, 배치)을 다 담지 못한다. 선택적 기능 플래그로 노출하고, 지원하지 않는 공급자는 대체 경로를 쓴다.
  - 평가 실행은 공급자를 실제로 호출하므로 비용이 든다. 실행 전 예상 비용을 보여 주고 확인을 받는다.
  - 평가 세트 주석에 사람 1명이 2~4일 걸린다. P1 1주차에 담당자를 정한다.
- 다시 검토할 신호
  - 한 공급자의 고유 기능 없이는 품질 목표를 맞출 수 없다는 평가 결과가 나올 때
  - 공급자의 데이터 사용 약관이 바뀌어 등록 조건을 못 지킬 때
