# ADR-NNNN: 결정 제목 (명사구로)

- 상태: 제안 | 채택 | 대체됨(→ ADR-XXXX) | 폐기
- 날짜: YYYY-MM-DD
- 관련: 이 결정이 나온 문서나 이슈 링크 (예: [ROADMAP.md D2](../v2/ROADMAP.md#결정-필요-사항))

## 맥락 (Context)

무엇을 정해야 했고 왜 지금 정해야 했는지 쓴다. 제약(예산, 호스트, 1인 유지보수, 일정), 검토한 선택지와 각 선택지의 장단점을 사실 위주로 적는다. 나중에 이 ADR만 읽은 사람이 "그때 왜 이렇게 했지?"에 답할 수 있어야 한다.

## 결정 (Decision)

정한 것을 한두 문단으로 쓴다. "우리는 ~한다"처럼 능동형으로 쓰고, 하지 않기로 한 것도 적는다.

## 결과 (Consequences)

- 좋아지는 것
- 감수하는 것(비용, 복잡도, 잠금)
- 이 결정을 다시 검토할 신호(트리거)

## 메모

선택 사항. 근거 자료, 측정값, 후속 작업 링크.
